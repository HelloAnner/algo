# 复习流程

触发："今天复习什么"、"开始复习"、"这题复习完了"、"我的进度怎么样"。

## 查看待复习

```bash
algo today
```

输出按紧迫度排序（逾期在前），每行带上次评分。把清单给用户，推荐从第一道开始。

## 开始复习某道

```bash
algo open <slug>     # 或 algo open（自动开最紧的一道）
```

复习建议（说给用户）：
1. 先不看讲解，在右侧编辑器默写最优解。
2. 写不出来/不确定 → 看左侧讲解和自己的划线评论、笔记。
3. 默写完对照讲解区代码。

## 记录复习结果

```bash
algo done <slug> --rating <1-5>
```

评分标准（用户说不清就按这个帮他定）：

| 评分 | 状态 | 效果 |
|---|---|---|
| 5 | 秒答，肌肉记忆 | 间隔 ×2.5 |
| 4 | 顺利写出，小卡顿 | 间隔 ×2 |
| 3 | 看了提示才写出来 | 间隔 ×1.3 |
| 2 | 基本不会，看了解答 | 重置为 1 天 |
| 1 | 完全没印象 | 重置为 1 天 |

首次复习：rating≥4 → 2 天后，3 → 1 天后。

## 批量复习会话

用户说"开始复习"时：
1. `algo today` 拿清单。
2. 一道一道来：`algo open` → 等用户说结果 → `algo done <slug> --rating N`。
3. 全部完成后再 `algo today` 确认清空，顺手 `algo stats` 展示成果。

## 进度总览

```bash
algo stats     # 总题数 / 复习次数 / 连续天数 / 待复习
algo list      # 按主题分组，●=待复习
```
