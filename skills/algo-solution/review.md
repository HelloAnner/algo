# 复习流程

触发："今天复习什么"、"开始复习"、"这题复习完了"、"我的进度怎么样"。

## 查看待办

```bash
algo today
```

输出分两个区：**复习**（逾期在前，带阶梯数和 ⚠困难 标记）和**今日新学**（每题有 `plan` 计划日，每天 2 道自动顺延；题库新题不足 2 道时 CLI 会告警，此时提示用户补题）。把清单给用户，推荐先清复习再新学。

## 开始复习某道

```bash
algo open <slug>     # 或 algo open（自动开最紧的一道）
```

复习建议（说给用户）：
1. 先不看讲解，在右侧编辑器默写最优解。
2. 写不出来/不确定 → 看左侧讲解和自己的划线评论、笔记。
3. 默写完对照讲解区代码。

## 记录复习结果

```bash
algo done <slug> --rating <1-5>
```

评分标准（艾宾浩斯阶梯，间隔天数 1→2→4→7→15→30→90）：

| 评分 | 状态 | 效果 |
|---|---|---|
| 5 | 秒答，肌肉记忆 | 跳一级（×2 速度推进阶梯） |
| 4 | 顺利写出，小卡顿 | 升一级 |
| 3 | 看了提示才写出来 | 原地重复当前级（密度不变） |
| 2 | 基本不会，看了解答 | 打回第 0 级，明天见，标 ⚠困难 |
| 1 | 完全没印象 | 同上 |

也可以在题解页面底部直接点星（掌握程度组件），效果和 `algo done` 完全一样。

## 批量复习会话

用户说"开始复习"时：
1. `algo today` 拿清单，先清复习区，再进新学区。
2. 一道一道来：`algo open` → 等用户说结果 → `algo done <slug> --rating N`（或用户自己在页面点星）。
3. 全部完成后 `algo stats` 展示成果。

## 新学（骨架填充）

150 道 Hot 题已用 `algo new` 建好骨架（`algo list` 里标"（骨架）"）。用户要学某道新题时，**按 [create.md](create.md) 第 3-7 步填充该题内容**（骨架已存在，跳过 `algo new`），填充完引导用户在页面底部点星完成首次学习。

## 进度总览

```bash
algo stats     # 总题数 / 复习次数 / 连续天数 / 待复习
algo list      # 按主题分组，●=待复习
```
