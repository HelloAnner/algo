## 思路

前缀和 + 哈希表。

设 `pre` 是当前位置的前缀和，那么「以当前位置结尾、和为 `k` 的子数组」的个数，等于前面出现过多少个前缀和正好是 `pre - k`（子数组的和 = 两个前缀和之差）。

所以遍历时：

1. 把 `pre` 累加上 `nums[i]`；
2. `ans += cnt[pre - k]`（`cnt` 记录每个前缀和出现过的次数）；
3. `cnt[pre]++`。

哈希表初始化为 `cnt[0] = 1`，表示「一个数都不选」的空前缀，这样从下标 0 开始的子数组也能被统计到。

## 复杂度

- 时间：O(n)，一次遍历，哈希表均摊 O(1)
- 空间：O(n)，最坏情况下有 n 个不同的前缀和

## 关键点

- 必须有 `cnt[0] = 1`，否则漏掉从第一个元素开始的子数组
- 元素可以是负数，所以**不能**用滑动窗口 / 双指针
- `pre - k` 可能越界或不存在，`unordered_map` 查不到就是 0，别直接 `cnt[pre - k]` 后判断（虽然也会插入 0，但会白白多建节点）
- 前缀和与答案都可能比较大，用 `long long`（答案最坏是 `n(n+1)/2`）
- `k` 用 `long long` 读入，范围到 `10^7` 也可以用 `int`，但统一成 `long long` 更省心
