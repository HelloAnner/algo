题目：和为 K 的子数组
链接：https://leetcode.cn/problems/subarray-sum-equals-k/
难度：中等

[题目描述]
给定一个整数数组 nums 和一个整数 k，请你统计并返回该数组中「和为 k 的连续子数组」的个数。

本题对应 LeetCode 560. Subarray Sum Equals K（文档第 88 题）。

用前缀和来看「连续子数组」的和：

    下标 j:      0    1    2    3
    nums:             1    1    1
    前缀和 pre:  0    1    2    3      pre[j] = nums[0] + ... + nums[j-1]，pre[0] = 0

    子数组 nums[i..j-1] 的和 = pre[j] - pre[i]

    以 j 结尾、和为 k 的子数组个数 = 前面出现过多少次前缀和 pre[j] - k

以示例 1（nums = [1,1,1]，k = 2）为例：

    j = 2：pre[2] = 2，pre[2] - k = 0，前面出现过 1 次（pre[0]）→ 命中 nums[0..1]
    j = 3：pre[3] = 3，pre[3] - k = 1，前面出现过 1 次（pre[1]）→ 命中 nums[1..2]
    合计 2 个。

[输入格式]
第一行两个整数 n 和 k，分别表示数组长度和目标值。
第二行 n 个整数 nums[0..n-1]，相邻数字用空格分隔。

[输出格式]
输出一个整数，表示和为 k 的连续子数组的个数。

[示例 1]
输入：
3 2
1 1 1
输出：
2
解释：[1,1]（前两个）和 [1,1]（后两个）是两种不同的情况，共 2 个。

[示例 2]
输入：
3 3
1 2 3
输出：
2
解释：[1,2] 与 [3] 的和都是 3。

[示例 3]
输入：
2 0
1 -1
输出：
1
解释：[1,-1] 的和为 0；元素可以为负数，所以不能用滑动窗口。

[数据范围]
- 1 <= n <= 20000
- -1000 <= nums[i] <= 1000
- -10^7 <= k <= 10^7
- 进阶：时间 O(n)、空间 O(n)
