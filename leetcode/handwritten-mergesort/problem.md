## 题目描述

实现**归并排序**：给定一个长度为 `n` 的整数数组 `nums`，用「分治 + 合并两个有序数组」的方式把数组按**非递减**顺序排好并输出。

要求时间复杂度为 O(n log n)，不要直接调用标准库的排序函数。

## 输入格式

第一行一个整数 `n`，表示数组长度。
第二行 `n` 个整数 `nums[0..n-1]`，相邻数字用空格分隔。

## 输出格式

输出一行 `n` 个整数，为从小到大排序后的数组，相邻数字用空格分隔。

## 示例

### 示例 1

输入：
```
5
5 3 8 1 2
```

输出：
```
1 2 3 5 8
```

解释：把 `[5,3,8,1,2]` 排序后得到 `[1,2,3,5,8]`。

### 示例 2

输入：
```
6
-1 4 4 -3 0 4
```

输出：
```
-3 -1 0 4 4 4
```

解释：含有负数与重复元素；归并时相等元素优先取左半边，排序是**稳定**的，结果仍是非递减序列。

### 示例 3

输入：
```
1
42
```

输出：
```
42
```

解释：只有一个元素的区间天然有序，递归直接返回。

## 数据范围

- `1 <= n <= 10^5`
- `-10^9 <= nums[i] <= 10^9`（在 32 位整数范围内）
