[思路]

归并排序是分治：

1. 分：把区间 [l, r] 从中点 mid = l + (r-l)/2 切开，递归排好左右两半 [l, mid] 和 [mid+1, r]。
2. 治：此时左右两半各自有序，用两个指针 i、j 分别扫两个有序段，每次把较小的那个写进临时数组 tmp；某一段先扫完后，把另一段的剩余部分直接接上；最后把 tmp[l..r] 拷回原数组。

为什么对（归纳）：长度 1 的区间有序，是归纳基础；假设左右两半已经有序，合并过程每次都取两个有序序列当前的最小值，因此 tmp 里是完整且有序的；归纳可得整个数组有序。

实现细节：

- 临时数组 tmp 只开一份（O(n)），每层合并复用它，避免每层都申请新数组；
- 相等元素优先取左边那个（a[i] <= a[j]），这样排序是稳定的；
- 也可以写成自底向上的迭代版本（步长 1、2、4、... 依次两两合并），省掉递归栈。

文档里的 Java 版本就是典型的自顶向下归并，「将大范围分成多个小部分，先保证小部分有序，再合并成较大的有序部分，直到整体有序」，时间复杂度 O(n log n)。

[复杂度]
时间：O(n log n)，共 log n 层，每层合并的代价是 O(n)   空间：O(n)（合并用的临时数组），递归栈 O(log n)

[关键点]
- 中点用 l + (r - l) / 2，避免 (l + r) 在大区间上溢出
- 合并的收尾不能漏：两个 while 分别把左段、右段剩下的元素搬过去，只写一个会丢数据
- 写回时目标下标是 l + k（不是 k）
- 稳定性：a[i] <= a[j] 取左边；写成 < 会破坏稳定性
- n == 0 / n == 1 要能直接跑通（递归边界写 l >= r 就自然覆盖了）

[C++ 代码]
// 归并排序
// https://leetcode.cn/problems/sort-an-array/
//
// 思路：分治，递归排好左右两半后，用双指针把两个有序段合并到临时数组再写回。
// 复杂度：时间 O(n log n) 空间 O(n)
#include <iostream>
#include <vector>

using namespace std;

vector<long long> tmp;  // 复用的临时数组

void mergeSort(vector<long long> &a, int l, int r) {
    if (l >= r) return;  // 长度 0 或 1，天然有序

    int mid = l + (r - l) / 2;
    mergeSort(a, l, mid);
    mergeSort(a, mid + 1, r);

    int i = l, j = mid + 1, k = l;
    while (i <= mid && j <= r) {
        // 相等时取左边，保证排序稳定
        if (a[i] <= a[j]) tmp[k++] = a[i++];
        else tmp[k++] = a[j++];
    }
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= r) tmp[k++] = a[j++];

    for (int t = l; t <= r; ++t) a[t] = tmp[t];
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    if (!(cin >> n)) return 0;

    vector<long long> a(n);
    for (auto &x : a) cin >> x;

    tmp.assign(n, 0);
    if (n > 0) mergeSort(a, 0, n - 1);

    for (int i = 0; i < n; ++i) {
        if (i) cout << ' ';
        cout << a[i];
    }
    cout << '\n';
    return 0;
}
