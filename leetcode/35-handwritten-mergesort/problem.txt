题目：归并排序
链接：https://leetcode.cn/problems/sort-an-array/
难度：中等

[题目描述]

实现归并排序：给定一个长度为 n 的整数数组 nums，用「分治 + 合并两个有序数组」的方式把数组按非递减顺序排好并输出。

要求时间复杂度为 O(n log n)，不要直接调用标准库的排序函数。

分治的过程（以 [5, 3, 8, 1, 2] 为例），先一路切分到单元素区间：

                       [5, 3, 8, 1, 2]
                      /                \
                 [5, 3]                [8, 1, 2]
                /      \              /        \
             [5]       [3]         [8]         [1, 2]
                                                /     \
                                              [1]     [2]

再自底向上两两合并（每次把两个有序段并成一个更长的有序段）：

     [5] + [3]              ->  [3, 5]
     [1] + [2]              ->  [1, 2]
     [8] + [1, 2]           ->  [1, 2, 8]
     [3, 5] + [1, 2, 8]     ->  [1, 2, 3, 5, 8]

合并两个有序段时用双指针，i 扫左段、j 扫右段、k 往临时数组里写：

     左段:  [3, 5]          右段:  [1, 2, 8]
             ^i                     ^j

     比较 a[i] 和 a[j]，谁小就把谁写进 tmp[k]：

     tmp:   [1, 2, 3, 5, 8]

     相等时取左边那个（a[i] <= a[j]），这样排序才是稳定的；
     某一段先扫完，就把另一段剩下的元素整体接上，最后再把 tmp 拷回原数组。

[输入格式]
第一行一个整数 n，表示数组长度。
第二行 n 个整数 nums[0..n-1]，相邻数字用空格分隔。

[输出格式]
输出一行 n 个整数，为从小到大排序后的数组，相邻数字用空格分隔。

[示例 1]
输入：
5
5 3 8 1 2
输出：
1 2 3 5 8
解释：把 [5,3,8,1,2] 排序后得到 [1,2,3,5,8]。

[示例 2]
输入：
6
-1 4 4 -3 0 4
输出：
-3 -1 0 4 4 4
解释：含有负数与重复元素；归并时相等元素优先取左半边，排序是稳定的，结果仍是非递减序列。

[示例 3]
输入：
1
42
输出：
42
解释：只有一个元素的区间天然有序，递归直接返回。

[数据范围]
- 1 <= n <= 10^5
- -10^9 <= nums[i] <= 10^9（在 32 位整数范围内）
