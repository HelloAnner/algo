## 题目描述

请你设计并实现一个满足 **LRU（最近最少使用）缓存**约束的数据结构，支持以下操作：

- `get(key)`：如果关键字 `key` 存在于缓存中，则返回关键字的值（总是正数），否则返回 `-1`。
- `put(key, value)`：如果关键字 `key` 已经存在，则变更其数据值；如果不存在，则插入该组「关键字-值」。当缓存容量达到上限时，它应该在写入新数据之前删除**最久未使用**的数据值，从而为新的数据值留出空间。

**进阶**：你是否可以在 O(1) 时间复杂度内完成这两种操作？

本题用「操作序列」的形式输入：第一行是缓存容量，之后每行一条操作，直到文件结束。

## 输入格式

第一行一个整数 `capacity`，表示缓存容量。

接下来若干行，每行是一条操作（直到文件结束）：

- `get key`
- `put key value`

## 输出格式

按输入顺序，对**每条 `get` 操作输出一行**：命中输出对应的值，未命中输出 `-1`。`put` 操作不产生任何输出。

## 示例

### 示例 1

输入：
```
2
put 1 1
put 2 2
get 1
put 3 3
get 2
put 4 4
get 1
get 3
get 4
```

输出：
```
1
-1
-1
3
4
```

解释：`put(1,1)`、`put(2,2)` 后缓存为 `{1=1, 2=2}`，此时 1 是最近使用的；`get(1)` 命中返回 1，并把 1 刷成最近使用；`put(3,3)` 时容量已满，淘汰最久未使用的 2，于是 `get(2)` 返回 -1；`put(4,4)` 淘汰 1，`get(1)` 返回 -1；`get(3)`、`get(4)` 分别返回 3、4。

### 示例 2

输入：
```
1
get 1
put 1 10
get 1
put 2 20
get 1
get 2
```

输出：
```
-1
10
-1
20
```

解释：容量为 1 时，写入新 key 一定会把旧 key 挤掉；一开始缓存为空，`get(1)` 未命中返回 -1。

### 示例 3

输入：
```
2
put 1 1
put 1 2
get 1
```

输出：
```
2
```

解释：key 已存在时是**更新值**（并刷成最近使用），不会新增条目、也不会触发淘汰，因此 `get(1)` 返回 2。

## 数据范围

- `1 <= capacity <= 3000`
- `0 <= key <= 10^4`
- `0 <= value <= 10^5`
- 操作总数不超过 `2 * 10^5` 条
- 要求 `get` 与 `put` 的平均时间复杂度为 O(1)
