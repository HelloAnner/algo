题目：有序数组中不重复元素的个数
链接：https://www.nowcoder.com/discuss/425581
难度：简单

[题目描述]

给定一个非递减有序的整数数组 nums（元素可能为负），请计算把所有元素平方之后，结果中不同数值的个数。

例如 nums = [-1, 0, 1]，平方后是 [1, 0, 1]，不同数值有 0 和 1 两个，答案是 2。

要求做到 O(n)：不要真的把数组平方后排序（那是 O(n log n)），请利用数组的有序性。

有序数组里绝对值是「两头大、中间小」，所以平方值可以从两端往中间归并：

   下标     0     1     2     3     4
          +-----+-----+-----+-----+-----+
   nums   | -4  | -1  |  0  |  3  | 10  |
          +-----+-----+-----+-----+-----+
   绝对值     4     1     0     3    10
             ^                       ^
             l                       r

   每一步比较 |nums[l]| 和 |nums[r]|，谁大谁就是剩余元素里最大的平方值；
   两者相等说明两个位置贡献同一个平方值，两个指针同时内移，只计数一次。

[输入格式]

第一行一个整数 n，表示数组长度。
第二行 n 个整数 nums[0..n-1]，非递减有序，相邻数字用空格分隔。

[输出格式]

一行一个整数，表示平方后不同数值的个数。

[示例 1]
输入：
5
-4 -1 0 3 10
输出：
5
解释：平方后为 [16, 1, 0, 9, 100]，共 5 个互不相同的数值。

[示例 2]
输入：
5
-7 -3 2 3 11
输出：
4
解释：平方后为 [49, 9, 4, 9, 121]，不同数值是 49, 9, 4, 121，共 4 个。

[示例 3]
输入：
5
-1 -1 0 1 1
输出：
2
解释：平方后为 [1, 1, 0, 1, 1]，不同数值只有 1 和 0。

[数据范围]

- 1 <= n <= 10^5
- -10^4 <= nums[i] <= 10^4
- 数组保证非递减有序
