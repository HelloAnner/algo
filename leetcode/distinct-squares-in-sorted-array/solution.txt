[思路]

数组有序时，平方值的大小由绝对值决定：负数是「越靠左绝对值越大」，非负数是「越靠右越大」，所以平方值从两端往中间看是递减的。用双指针 l = 0、r = n - 1 从两端向中间归并平方值：

   - 比较 abs(nums[l]) 与 abs(nums[r])，谁大谁就是当前剩余元素里最大的平方值；
   - 两者的绝对值相等时，两个位置贡献同一个平方值，l++、r-- 同时内移，只算一次；
   - 每产生一个平方值就和上一次记录的平方值比较，不同才让答案 +1，这样就完成了线性去重。

  nums = -4  -1   0   3  10
         ^                 ^
         l                 r        |l| = 4 < |r| = 10  ->  取 100（r--）
         ^             ^
         l             r            |l| = 4 > |r| = 3   ->  取 16 （l++）
             ^         ^
             l         r            |l| = 1 < |r| = 3   ->  取 9  （r--）
             ^     ^
             l     r                |l| = 1 > |r| = 0   ->  取 1  （l++）
                 ^
                l,r                 |l| = |r| = 0       ->  取 0，两指针同时内移

  输出序列：100 16 9 1 0（非递增），线性去重后仍是 5 个不同值。

正确性：每一步取出的都是剩余元素中绝对值最大者，也就是剩余平方值中的最大值，所以产生的序列是平方值的非递增序列；对这样的有序序列做「和上一个输出比较」的线性去重，得到的正好是不同数值的个数。

文档方法 1 是「先平方、再快排、最后遍历去重」，时间 O(n log n)，正确但不够快；方法 2 的双指针就是上面的做法。

[复杂度]
时间：O(n)（两个指针一共移动 n 次，每次 O(1)）   空间：O(1)（不计读入的数组）

[关键点]

- 比较的是 abs(nums[l])，不要直接比较 nums[l] < nums[r]（负数会出错）
- 绝对值相等时两个指针要同时移动，且只计数一次
- 「上一个平方值」的初值要写成不可能取到的哨兵（平方值非负，可用 -1），否则第一个 0 会被当成重复而漏计
- 平方值最大 10^8，用 long long 存比较稳妥，也方便把哨兵设成负数
- 算法依赖输入有序，本题已保证；若未排序需要先排序

[C++ 代码]
// 有序数组中不重复元素的个数（平方后不同值的个数）
// https://www.nowcoder.com/discuss/425581
//
// 思路：双指针从两端比较绝对值，按从大到小归并平方值并线性去重。
// 复杂度：时间 O(n) 空间 O(1)
#include <cstdlib>
#include <iostream>
#include <vector>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    if (!(cin >> n) || n <= 0) {
        cout << 0 << '\n';
        return 0;
    }

    vector<long long> nums(n);
    for (auto &x : nums) cin >> x;

    long long last = -1;  // 平方值非负，用 -1 当哨兵
    int count = 0;
    int l = 0, r = n - 1;
    while (l <= r) {
        long long a = llabs(nums[l]);
        long long b = llabs(nums[r]);
        long long cur;
        if (a > b) {
            cur = a * a;
            ++l;
        } else if (a < b) {
            cur = b * b;
            --r;
        } else {
            cur = a * a;
            ++l;
            --r;
        }
        if (cur != last) {
            ++count;
            last = cur;
        }
    }

    cout << count << '\n';
    return 0;
}
