## 题目描述

输入一个**递增排序**的数组 `nums` 和一个目标数字 `target`，在数组中查找两个数，使得它们的和正好是 `target`。如果有多对数字的和等于 `target`，输出**任意一对**即可（输出的两个数中较小的写在前面）。

> 原文档这一节叫「找出和为 k 的数对」，对应 LeetCode [剑指 Offer 57. 和为 s 的两个数字](https://leetcode.cn/problems/he-wei-sde-liang-ge-shu-zi-lcof/)（该题官方 slug 是拼音、可读性差，因此目录名借用了同型题 LC 167 的英文 slug）。
>
> 注意与 LC 1「两数之和」、LC 167「两数之和 II - 输入有序数组」的区别：那两题返回的是**下标**，本题返回的是**数值**；共同点是数组已经有序。

## 输入格式

第一行两个整数 `n` 和 `target`，`n` 是数组长度，`target` 是目标和。
第二行 `n` 个整数 `nums[0..n-1]`（**非递减**有序），相邻数字用空格分隔。

## 输出格式

输出一行两个整数，为满足 `nums[i] + nums[j] == target` 的一对数（`i < j`，两个位置不同），**较小的在前**。

若有多对答案，输出任意一对均可：本题解输出的是双指针从两端向中间收缩时**最先遇到**的那一对。
输入保证至少存在一对满足条件的数字。

## 示例

### 示例 1

输入：
```
4 9
2 7 11 15
```

输出：
```
2 7
```

解释：`2 + 7 = 9`，返回 `[2,7]`（写成 `7 2` 也判对，但本题解固定输出小的在前）。

### 示例 2

输入：
```
6 40
10 26 30 31 47 60
```

输出：
```
10 30
```

解释：`10 + 30 = 40`（文档里的示例 2），数组中只有这一对。

### 示例 3

输入：
```
3 5
1 2 3
```

输出：
```
2 3
```

解释：`2 + 3 = 5`；左指针先停在 1（`1+3=4<5` 所以右指针不动、左指针右移），再比较 `2+3` 命中。

## 数据范围

- `1 <= n <= 10^5`
- `1 <= nums[i] <= 10^6`
- 数组按**非递减**顺序排列（可能有重复元素）
- `1 <= target <= 2 * 10^6`
- 保证至少存在一对数字之和等于 `target`
