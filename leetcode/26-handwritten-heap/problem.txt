题目：手写堆（大根堆 / 小根堆）
链接：
难度：中等

[题目描述]

请手写一个二叉堆（heap），支持大根堆和小根堆两种模式，并实现下列操作：

- push x：向堆中插入整数 x；
- pop：删除并输出堆顶元素；
- peek：输出堆顶元素（不删除）；
- size：输出当前堆中元素个数。

堆用数组存储一棵完全二叉树：下标 i 的父节点是 (i-1)/2，左右孩子是 2i+1 和 2i+2。大根堆满足「父节点 >= 子节点」，堆顶是最大值；小根堆满足「父节点 <= 子节点」，堆顶是最小值。

要求自己实现上浮（shiftUp）与下沉（shiftDown），不能直接用 std::priority_queue。

堆的形状与下标（完全二叉树，下标从 0 开始，用数组顺序存储）：

                0
              /   \
             /     \
            1       2
           / \     / \
          3   4   5   6

     数组:  [ 0, 1, 2, 3, 4, 5, 6 ]   <- 每个下标存一个元素

     下标 i 的父节点 = (i - 1) / 2      （整除；根没有父节点）
     下标 i 的左孩子 = 2 * i + 1
     下标 i 的右孩子 = 2 * i + 2

以示例 1 的小根堆为例，依次插入 5、3、8 之后堆长这样：

              3
            /   \
           5     8
        数组: [3, 5, 8]

再 push 1：先把它放到数组末尾（下标 3），再和父节点一路比较上浮：

   [3,5,8]        [3,5,8,1]       [3,1,8,5]       [1,3,8,5]
      3               3               3               1
     / \             / \             / \             / \
    5   8           5   8           1   8           3   8
                   /               /               /
                  1               5               5

1 比父节点 5 小就交换，再比新的父节点 3 小再交换，到根停止。

pop 时方向相反：堆顶先取出来，把数组末尾的元素搬到堆顶（保持完全二叉树的形状），再和两个孩子里更优先的那个比较、一路下沉：

   对 [1,3,8,5] 做 pop：取出堆顶 1，末尾的 5 补到堆顶，然后下沉

   [1,3,8,5]         [5,3,8]           [3,5,8]
       1                 5                 3
      / \               / \               / \
     3   8             3   8             5   8
    /
   5

   5 的两个孩子是 3 和 8，更小的是 3，交换之后 5 变成叶子，下沉停止。

[输入格式]
第一行两个整数 q 和 type：q 表示操作个数，type = 0 表示小根堆，type = 1 表示大根堆。
接下来 q 行，每行一个操作，格式为上面列出的四种操作之一，push 后跟一个整数 x。

保证 pop / peek 时堆非空。

[输出格式]
对每个 pop / peek / size 操作输出一行结果：pop 输出被删除的堆顶，peek 输出当前堆顶，size 输出元素个数。
push 不产生输出。

[示例 1]
输入：
8 0
push 5
push 3
push 8
peek
pop
push 1
pop
size
输出：
3
3
1
2
解释：依次插入 5、3、8 后小根堆堆顶是 3，peek 输出 3；pop 删掉 3 并输出 3；再插入 1 后堆顶是 1，pop 输出 1；最后堆里剩 2 个元素。

[示例 2]
输入：
7 1
push 5
push 3
push 8
peek
pop
size
pop
输出：
8
8
2
5
解释：同样插入 5、3、8，大根堆堆顶是 8；pop 删除 8 后剩 {5, 3}，元素个数 2，再 pop 输出 5。

[示例 3]
输入：
4 0
push 42
peek
pop
size
输出：
42
42
0
解释：堆里只有一个元素时，pop 之后不要再做下沉（否则会越界），size 变成 0。

[数据范围]
- 1 <= q <= 10^5
- type 取 0（小根堆）或 1（大根堆）
- -10^9 <= x <= 10^9
- 任意时刻堆中元素个数不超过 10^5
- 时间复杂度要求：push / pop 为 O(log n)，peek / size 为 O(1)

[备注]
- 非 LeetCode 题，来自《手撕字节跳动面试时出现过的算法题》第 32 题：讲一讲 heap 是什么，并手写一个堆。
