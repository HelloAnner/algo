[思路]
后序遍历 = 左 → 右 → 根。递归照定义写很简单，但题目要求迭代，这里用一个「前序变形 + 整体反转」的技巧：

1. 前序遍历是「根 → 左 → 右」：入栈时先压右孩子、再压左孩子，出栈顺序就是「根 → 左 → 右」。
2. 把入栈顺序改成先压左孩子、再压右孩子，出栈顺序就变成了「根 → 右 → 左」。
3. 把这个序列整体反转，得到的正好是「左 → 右 → 根」，也就是后序遍历。

具体流程：

- 栈里先压入根节点；
- 每次弹出栈顶 p，把 p->val 追加到答案数组尾部；
- 再依次把 p->left、p->right 压栈（左先入栈，右后入栈，这样右孩子先出栈）；
- 栈空后，把答案数组 reverse 一次即可。

用示例 1（1 null 2 3）走一遍：

    出栈顺序（根->右->左）：1, 2, 3
    压栈细节：            [1] -> 弹 1，压左(null 跳过)、压 2
                          [2] -> 弹 2，压 3
                          [3] -> 弹 3
    整体反转：            3, 2, 1     <- 后序（左->右->根）

文档里的 Java 解法用 LinkedList.addFirst（头插）实现，等价于「先尾插、最后反转」；C++ 里用 vector + std::reverse 更省事，也避免了链表节点的开销。

另一种等价写法是「双栈法」或「栈中记录节点是否已访问」的标记法，本质都是保证根节点在左右孩子之后输出。

[复杂度]
时间：O(n)，每个节点入栈、出栈、写入答案各一次，最后整体反转一次
空间：O(n)，显式栈与答案数组各 O(n)

[关键点]
- 压栈顺序不能写反：必须先左后右压栈，出栈才是「右、左」，反转后才符合后序；写成「先右后左」就退化成前序遍历的镜像
- 反转是整个数组反转一次，不是在每个子树内部各反转一次
- 空树要输出空行（题目允许 n = 0），注意不要多输出空格
- 本题输入是 LeetCode 的层序数组表示，建树时要按「每个非空节点依次消耗左、右两个孩子 token」来解析，null 只是占位、不入队
- 别用递归：题目要求迭代，而且深链状树容易爆栈

[C++ 代码]
// 二叉树的后序遍历（非递归）
// https://leetcode.cn/problems/binary-tree-postorder-traversal/
//
// 思路：用迭代前序的镜像（根 -> 右 -> 左）收集节点，最后整体反转，即得后序（左 -> 右 -> 根）。
// 复杂度：时间 O(n) 空间 O(n)
#include <algorithm>
#include <iostream>
#include <queue>
#include <string>
#include <vector>

using namespace std;

struct Node {
    int val;
    int left;
    int right;
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    // 读入全部 token（层序数组表示，null 表示空节点）
    vector<string> tok;
    string s;
    while (cin >> s) tok.push_back(s);

    if (tok.empty() || (tok.size() == 1 && tok[0] == "null")) {
        cout << '\n';  // 空树：输出空行
        return 0;
    }

    // 按层序建树：每个非空节点依次消耗「左孩子、右孩子」两个 token
    vector<Node> tr;
    tr.push_back(Node{stoi(tok[0]), -1, -1});
    queue<int> q;
    q.push(0);
    size_t i = 1;
    while (!q.empty() && i < tok.size()) {
        int u = q.front();
        q.pop();
        if (i < tok.size()) {
            if (tok[i] != "null") {
                tr.push_back(Node{stoi(tok[i]), -1, -1});
                tr[u].left = static_cast<int>(tr.size()) - 1;
                q.push(tr[u].left);
            }
            ++i;
        }
        if (i < tok.size()) {
            if (tok[i] != "null") {
                tr.push_back(Node{stoi(tok[i]), -1, -1});
                tr[u].right = static_cast<int>(tr.size()) - 1;
                q.push(tr[u].right);
            }
            ++i;
        }
    }

    // 迭代前序的镜像：根 -> 右 -> 左
    vector<int> res;
    vector<int> st;
    st.push_back(0);
    while (!st.empty()) {
        int u = st.back();
        st.pop_back();
        res.push_back(tr[u].val);
        if (tr[u].left != -1) st.push_back(tr[u].left);    // 左孩子先入栈，
        if (tr[u].right != -1) st.push_back(tr[u].right);  // 右孩子后入栈 -> 右孩子先出栈
    }

    // 整体反转 -> 左 -> 右 -> 根
    reverse(res.begin(), res.end());

    for (size_t k = 0; k < res.size(); ++k) {
        if (k) cout << ' ';
        cout << res[k];
    }
    cout << '\n';
    return 0;
}
