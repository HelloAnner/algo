[思路]
两个链表都是「个位在首部」，正好和手算加法「从低位加起」的顺序一致，所以从两个链表的头节点开始同步遍历即可：

1. 用哑结点 dummy + 尾指针 tail 承接结果链表，尾插的顺序天然就是从低位到高位；
2. 每一轮计算 sum = carry + (l1 ? l1->val : 0) + (l2 ? l2->val : 0)；
3. 当前位是 sum % 10，新的进位是 sum / 10；
4. 某个链表先走到 nullptr 就当作 0 继续参与计算。

     l1:  7 -> 1 -> 6 -> null
     l2:  5 -> 9 -> 2 -> null
          |    |    |    |
          v    v    v    v
         +--+ +--+ +--+  null（都走完了，但 carry 还要再看一眼）
         | 2| | 1| | 9| -> null
         +--+ +--+ +--+
        dummy 尾插，天然低位在前

循环条件写成 while (l1 || l2 || carry) 是关键：它一次性覆盖了「两条链表长度不等」和「最高位还要再进一位」（如 5 + 999 = 1004）两种情况，循环结束后不需要再补节点。

进阶（数位正向存放）的两种做法：

- 先原地反转两条链表（三指针迭代），再套用上面的函数，最后按需再反转回来；
- 或者把两条链表的数位分别压入两个栈，再不断弹栈相加，效果等价。

[复杂度]
时间：O(max(n, m))，每个数位只参与一次加法
空间：O(1) 额外空间（返回的结果链表不计入）

[关键点]
- 循环条件漏掉 carry 会在最高位丢进位（示例 2 就是这种情况）
- 用哑结点可以免去「结果链表第一个节点」的特判
- 走完的链表不要继续取 ->val，必须判空，否则会解引用空指针
- 进阶的链表反转要写对顺序：先存 next，再改 cur->next = pre，最后整体后移

[C++ 代码]
// 链表求和（面试题 02.05）
// https://leetcode.cn/problems/sum-lists-lcci/
//
// 思路：两条链表都是个位在首部，从头同步遍历，逐位相加并维护进位，用哑结点尾插结果链表。
// 复杂度：时间 O(max(n, m)) 空间 O(1)（不含结果链表）
#include <algorithm>
#include <iostream>
#include <vector>

using namespace std;

struct ListNode {
    int val;
    ListNode *next;
    explicit ListNode(int v) : val(v), next(nullptr) {}
};

// 把数组里的数位按顺序建成链表；节点内存统一放在 pool 中，省去手工 new/delete
ListNode *buildList(const vector<int> &digits, vector<ListNode> &pool) {
    ListNode dummy(0);
    ListNode *tail = &dummy;
    for (int d : digits) {
        pool.emplace_back(d);
        tail->next = &pool.back();
        tail = tail->next;
    }
    return dummy.next;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    if (!(cin >> n)) return 0;
    vector<int> a(n);
    for (int &x : a) cin >> x;
    cin >> m;
    vector<int> b(m);
    for (int &x : b) cin >> x;

    // pool 预留足够空间：两条链表 + 结果链表（最长 max(n, m) + 1 位）
    vector<ListNode> pool;
    pool.reserve(n + m + max(n, m) + 1);
    ListNode *l1 = buildList(a, pool);
    ListNode *l2 = buildList(b, pool);

    ListNode dummy(0);
    ListNode *tail = &dummy;
    int carry = 0;
    while (l1 != nullptr || l2 != nullptr || carry != 0) {
        int sum = carry;
        if (l1 != nullptr) { sum += l1->val; l1 = l1->next; }
        if (l2 != nullptr) { sum += l2->val; l2 = l2->next; }
        pool.emplace_back(sum % 10);
        tail->next = &pool.back();
        tail = tail->next;
        carry = sum / 10;
    }

    bool first = true;
    for (ListNode *p = dummy.next; p != nullptr; p = p->next) {
        if (!first) cout << ' ';
        first = false;
        cout << p->val;
    }
    cout << '\n';
    return 0;
}
