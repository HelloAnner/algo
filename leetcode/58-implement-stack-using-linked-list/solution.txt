[思路]

用单链表 + 头插法实现栈：链表头就是栈顶。

- push：新建节点，把它的 next 指向当前表头，再让表头指向它 —— O(1)；
- pop：记下头节点的值，表头后移一位，删掉旧头 —— O(1)；
- top / empty / size：直接读表头或计数器 —— O(1)。

文档里的 Java 版本用双向链表 + 尾指针保存栈顶。其实单链表就够：栈只在一端进出，头插法天然满足。反过来，如果坚持用「尾指针 + 单向链表」，pop 时拿不到前驱，就得 O(n) 找前一个节点 —— 这正是文档的版本要维护 pre 指针的原因。

[复杂度]
时间：push / pop / top / empty / size 全部 O(1)   空间：O(k)，k 是栈内元素个数

[关键点]
- 链表节点要手动 new / delete：pop 记得释放被弹出的节点，析构函数里把剩下的节点全部释放，避免内存泄漏
- push 的顺序不能反：先让新节点指向旧表头，再更新表头，否则会丢链
- pop 要先把值存下来再改指针
- size 用一个计数器维护，不要每次遍历链表去数（那样就 O(n) 了）

[C++ 代码]
// 用链表实现栈
// 字节跳动面试手写题（《手撕字节跳动面试时出现过的算法题》第 84 题）
//
// 思路：单链表 + 头插法，链表头就是栈顶，push / pop / top / empty / size 都是 O(1)。
//       文档的 Java 版本用双向链表 + 尾指针，这里用更简单的单向链表。
// 复杂度：各操作时间 O(1) 空间 O(k)（k 为栈内元素个数）
#include <iostream>
#include <string>

using namespace std;

struct Node {
    int val;
    Node *next;
    explicit Node(int v) : val(v), next(nullptr) {}
};

class LinkedStack {
public:
    LinkedStack() : head_(nullptr), size_(0) {}

    ~LinkedStack() {
        while (head_ != nullptr) {
            Node *dead = head_;
            head_ = head_->next;
            delete dead;
        }
    }

    // 头插：新节点成为新的栈顶
    void push(int v) {
        Node *node = new Node(v);
        node->next = head_;
        head_ = node;
        ++size_;
    }

    int top() const { return head_->val; }

    int pop() {
        Node *dead = head_;
        int v = dead->val;
        head_ = dead->next;
        delete dead;
        --size_;
        return v;
    }

    bool empty() const { return head_ == nullptr; }

    int size() const { return size_; }

private:
    Node *head_;
    int size_;
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int q;
    if (!(cin >> q)) return 0;

    LinkedStack st;
    string op;
    for (int i = 0; i < q; ++i) {
        cin >> op;
        if (op == "push") {
            int x;
            cin >> x;
            st.push(x);
        } else if (op == "pop") {
            cout << st.pop() << '\n';
        } else if (op == "top") {
            cout << st.top() << '\n';
        } else if (op == "empty") {
            cout << (st.empty() ? "true" : "false") << '\n';
        } else if (op == "size") {
            cout << st.size() << '\n';
        }
    }
    return 0;
}
