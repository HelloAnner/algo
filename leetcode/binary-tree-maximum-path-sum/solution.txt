[思路]
树上的路径一定有一个最高点（离根最近的那个节点），路径就是从这个最高点向下走到某个节点、再向下走到另一个节点，左右两条分支各自是一条不含分叉的链。于是对每个节点，把它当作最高点，就能算出「以它拐弯」的最优路径。

定义 maxGain(node)：从 node 出发向下延伸到某条链所能得到的最大和（这条链必须含有 node，只能选左或右一条分支，因为再往上只能走一条路）。

    int maxGain(TreeNode* node) {
        if (node == nullptr) return 0;
        int left  = max(maxGain(node->left), 0);   // 负数不如不选
        int right = max(maxGain(node->right), 0);
        ans = max(ans, node->val + left + right);  // 以 node 为最高点拐弯
        return node->val + max(left, right);       // 向上只能贡献一条分支
    }

两个关键点：

1. 子树贡献为负就丢弃：max(gain, 0) 表示这条下行链可以「不走」，因为它只会让路径和变小；
2. 更新答案与返回值是两件事：更新答案时允许左右两条分支同时要（路径在 node 处拐弯，不能再往上）；返回给父节点时只能带一条分支（带两条就分叉了，不构成一条路径）。

答案初值取 INT_MIN 而不是 0，因为题目保证树非空、且路径至少要含一个节点，全负数时答案应该是「最大的那个负数」。

[复杂度]
时间：O(n)，每个节点访问一次
空间：O(h) 递归栈，h 为树高；最坏 O(n)

[关键点]
- 答案初值必须是 INT_MIN（或 -inf），写 0 会在全负数用例上错
- 两个 max(..., 0) 不能漏：漏掉就会把负贡献也算进路径
- 更新 ans 用 node->val + left + right，返回值用 node->val + max(left, right)，两者别写混
- 题目说路径不一定经过根节点，所以必须在递归每个节点时都尝试更新 ans，不能只在根节点结算
- 本数据范围内最大和约 3 * 10^7，int 够用；如果值域或节点数放大，改用 long long

[C++ 代码]
// 二叉树中的最大路径和（124）
// https://leetcode.cn/problems/binary-tree-maximum-path-sum/
//
// 思路：后序 DFS，每个节点尝试作为路径最高点拐弯更新答案，向上只返回一条分支的最大贡献（负贡献取 0）。
// 复杂度：时间 O(n) 空间 O(h)（递归栈）
#include <algorithm>
#include <climits>
#include <iostream>
#include <queue>
#include <string>
#include <vector>

using namespace std;

struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    explicit TreeNode(int v) : val(v), left(nullptr), right(nullptr) {}
};

// 按层序数组建树（"null" 表示空节点），节点内存由 pool 持有
TreeNode *buildTree(const vector<string> &tokens, vector<TreeNode> &pool) {
    if (tokens.empty() || tokens[0] == "null") return nullptr;
    pool.reserve(tokens.size());
    pool.emplace_back(stoi(tokens[0]));
    TreeNode *root = &pool.back();

    queue<TreeNode *> q;
    q.push(root);
    size_t i = 1;
    while (!q.empty() && i < tokens.size()) {
        TreeNode *cur = q.front();
        q.pop();
        if (i < tokens.size()) {
            const string &s = tokens[i++];
            if (s != "null") {
                pool.emplace_back(stoi(s));
                cur->left = &pool.back();
                q.push(cur->left);
            }
        }
        if (i < tokens.size()) {
            const string &s = tokens[i++];
            if (s != "null") {
                pool.emplace_back(stoi(s));
                cur->right = &pool.back();
                q.push(cur->right);
            }
        }
    }
    return root;
}

int best = INT_MIN;

// 返回从 node 向下延伸一条链能得到的最大和；同时用「以 node 拐弯」的路径更新全局答案
int maxGain(TreeNode *node) {
    if (node == nullptr) return 0;
    int left = max(maxGain(node->left), 0);
    int right = max(maxGain(node->right), 0);
    best = max(best, node->val + left + right);
    return node->val + max(left, right);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    if (!(cin >> n)) return 0;
    vector<string> tokens(n);
    for (string &s : tokens) cin >> s;

    vector<TreeNode> pool;
    TreeNode *root = buildTree(tokens, pool);
    maxGain(root);
    cout << best << '\n';
    return 0;
}
