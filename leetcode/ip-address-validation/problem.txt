题目：IP 地址判断（IPv4 合法性校验）
链接：https://leetcode.cn/problems/validate-ip-address/
难度：中等

[题目描述]

给定若干个字符串，逐个判断它们是否是合法的 IPv4 地址。

原文档第 27 题「ip 判断」问的是「有一个几十万条 IP 的地址库，如何判断某个 IP 是否在库中」，属于系统设计 / 场景类问题，没法用 stdin -> stdout 判题。这里把它改造成可以直接判题的 IPv4 字符串合法性校验（对应 LeetCode 468「验证 IP 地址」的 IPv4 部分，本题不考察 IPv6）。

合法 IPv4 地址的判定规则（必须同时满足）：

1. 恰好由 4 段组成，段与段之间用 . 分隔；
2. 每一段非空，且每个字符都是数字 0 ~ 9；
3. 每一段的数值在 0 ~ 255 之间（含端点）；
4. 不允许前导零：0 本身合法，00、01、012 都非法；
5. 整个字符串中除了数字和 .，不允许出现其他任何字符（空格、字母、-、+、: 等一律非法）；
6. 空字符串非法；含 : 的 IPv6 地址（如 ::1）一律判非法。

一个合法地址的切分示意图（恰好 4 段，每段 0 ~ 255 且无前导零）：

    192 . 168 .  1  . 1
     |     |     |    |
     |     |     |    +-- 第 4 段
     |     |     +------- 第 3 段
     |     +------------- 第 2 段
     +------------------- 第 1 段

    非法示例：
    192.168.01.1   第 2 段有前导零
    256.0.0.1      第 1 段数值 256 > 255
    1..2.3         有空的段
    1.2.3.4.5      段数是 5，不是 4
    192.168.1.a    出现了数字和 . 之外的字符

[输入格式]

第一行一个整数 n，表示待判定的字符串个数。

接下来 n 行，每行一个待判定的字符串（整行读入，可能为空行，也可能含有空格；每行长度不超过 100）。

[输出格式]

输出 n 行，第 i 行对应第 i 个字符串的判定结果：

- 合法输出 valid
- 非法输出 invalid

[示例 1]
输入：
4
192.168.1.1
192.168.01.1
256.0.0.1
192.168.1
输出：
valid
invalid
invalid
invalid
解释：第 1 个是合法地址；第 2 个第二段有前导零；第 3 个第一段 256 超出了 0~255；第 4 个只有 3 段。

[示例 2]
输入：
6
0.0.0.0
255.255.255.255
1.2.3.4.5
192.168.1.a
1..2.3
12.34.5678
输出：
valid
valid
invalid
invalid
invalid
invalid
解释：0.0.0.0 与边界值 255.255.255.255 合法；段数为 5、含字母、出现空段、某段数值超过 255 分别对应后面四个非法串。

[示例 3]
输入（第 2 行是一个空行）：
3
192.168.1.1

10.0.0.1
输出：
valid
invalid
valid
解释：空行对应空字符串，空字符串不是合法 IPv4，判 invalid；读入时不能跳过空行，否则后面所有行的答案都会错位。

[数据范围]

- 1 <= n <= 10^4
- 每个待判定字符串的长度 0 <= |s| <= 100（可能为空行）
- 只考察 IPv4，不考察 IPv6

[备注]

- 空字符串非法；带尾随空格或 \r 的串按规则判非法（真实工程里可以先 strip，本题规则不 strip）
