题目：求平方根（带精度）
链接：https://leetcode.cn/problems/sqrtx/
难度：中等

[题目描述]
实现一个求平方根的函数：给定非负实数 x 和精度 e，返回 √x 的近似值，要求误差不超过 e。

原题是「函数入参」形式，即像 fn(4.1, 0.001)、fn(501.1, 0.001)、fn(0.045, 0.001) 这样按「目标数字 + 精度」调用。这里改造成等价的 stdin/stdout 形式。

把答案想成数轴上的一个点，二分法每轮把「一定包含答案」的区间折半：

    0 = low                mid                 high = max(1, x)
    +-----------------------+-----------------------+
        mid * mid < x             mid * mid >= x
      答案在右半边 →            ← 答案在左半边
      low = mid                  high = mid

迭代固定次数后，low 就是 √x 的近似值。

[输入格式]
一行两个数 x、e，用空格分隔：

- x 是十进制小数，0 <= x <= 10^9；
- e 的写法固定为 1、0.1、0.01、0.001、0.0001、0.00001、0.000001 之一，即 e = 10^-k（k 为 e 的小数位数，0 <= k <= 6）。

[输出格式]
输出一行 √x，保留 k 位小数（k 为 e 的小数位数），四舍五入。

[示例 1]
输入：
4.1 0.001
输出：
2.025
解释：√4.1 ≈ 2.0248457，保留 3 位小数得 2.025。

[示例 2]
输入：
0.045 0.001
输出：
0.212
解释：√0.045 ≈ 0.2121320，保留 3 位小数得 0.212。

[示例 3]
输入：
501.1 0.001
输出：
22.385
解释：√501.1 ≈ 22.385261，保留 3 位小数得 22.385。

[数据范围]
- 0 <= x <= 10^9
- e ∈ {1, 0.1, 0.01, 0.001, 0.0001, 0.00001, 0.000001}
- 二分迭代 100 次后 double 的精度约为 1e-15，远高于任何允许的 e；输出按「保留 k 位小数」判定，因此实际精度必须优于 e
