[思路]

动态规划（文档方法 1）：

设 dp[i] 表示长度为 i 的绳子至少剪一刀之后各段乘积的最大值。枚举第一刀剪下的长度 j（1 <= j < i），剩下的 i - j 有两种选择：

- 不再剪：乘积为 j * (i - j)；
- 继续剪：乘积为 j * dp[i - j]。

于是 dp[i] = max{ max(j * (i - j), j * dp[i - j]) }，其中 1 <= j < i；初值 dp[1] = 1，答案 dp[n]（n <= 3 时直接返回 n - 1）。

注意 dp[i] 与 i 本身的区别：dp[i] 强制至少剪一刀，而转移里允许剩下那段不剪，所以 j * (i - j) 这一项不能漏，否则 dp[4] 会算成 3 而不是 4。

枚举第一刀不会重复也不会漏：任意一种剪法，第一刀的长度是确定的 j，剩下的部分要么不剪要么继续剪，正好对应两项。

文档方法 2 是贪心：尽量剪成长度 3，余数为 0 时是 3^(n/3)，余数为 1 时把最后的 3 + 1 换成 2 * 2，余数为 2 时再乘 2（n <= 3 时返回 n - 1）。结论正确，但要额外证明「不会用到长度 >= 5 的段，且 3 比 2 更划算」，面试里可以两种都讲。

[复杂度]
时间：O(n^2)，n <= 58 时最多几千次运算   空间：O(n)

[关键点]
- n <= 3 时必须剪且只能剪成 1 和 n - 1，答案是 n - 1（不是 n）
- 转移里 j * (i - j) 与 j * dp[i - j] 都要取最大，漏掉前者会偏小
- dp 下标从 1 开始，dp[0] 不用（没有长度为 0 的绳子）
- 用 long long 更稳；本题 n = 58 的答案 1549681956 刚好没超 int
- 不要用 pow(3, n / 3) 直接算贪心版本，浮点会有精度风险，建议快速幂或 DP

[C++ 代码]
// 剪绳子（剑指 Offer 14- I）
// https://leetcode.cn/problems/jian-sheng-zi-lcof/
//
// 思路：dp[i] 为长度 i 至少剪一刀的最大乘积，枚举第一刀长度 j 做转移。
// 复杂度：时间 O(n^2) 空间 O(n)
#include <algorithm>
#include <iostream>
#include <vector>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    if (!(cin >> n)) return 0;
    if (n <= 3) {
        // 2 -> 1 + 1 = 1, 3 -> 1 + 2 = 2
        cout << n - 1 << '\n';
        return 0;
    }

    vector<long long> dp(n + 1, 0);
    dp[1] = 1;
    dp[2] = 1;
    dp[3] = 2;
    for (int i = 4; i <= n; ++i) {
        for (int j = 1; j < i; ++j) {
            long long cut = (long long)j * (i - j);      // 剩下的不剪
            long long keep = (long long)j * dp[i - j];   // 剩下的继续剪
            dp[i] = max(dp[i], max(cut, keep));
        }
    }

    cout << dp[n] << '\n';
    return 0;
}
