## 题目描述

给你一根长度为 `n` 的绳子，请把绳子剪成整数长度的 `m` 段（`m`、`n` 都是整数，`n > 1` 且 `m > 1`），每段绳子的长度记为 `k[0], k[1], ..., k[m-1]`。

请问 `k[0] * k[1] * ... * k[m-1]` 可能的最大乘积是多少？

## 输入格式

一行一个整数 `n`。

## 输出格式

一行一个整数，表示最大乘积。

## 示例

### 示例 1

输入：
```
2
```

输出：
```
1
```

解释：`2 = 1 + 1`，`1 x 1 = 1`（必须剪成两段，所以答案是 1）。

### 示例 2

输入：
```
10
```

输出：
```
36
```

解释：`10 = 3 + 3 + 4`，`3 x 3 x 4 = 36`。

### 示例 3

输入：
```
8
```

输出：
```
18
```

解释：`8 = 2 + 3 + 3`，`2 x 3 x 3 = 18`。

## 数据范围

- `2 <= n <= 58`
- 答案在 32 位有符号整数范围内（`n = 58` 时答案为 1549681956）
