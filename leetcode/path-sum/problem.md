## 题目描述

给定一棵二叉树的根节点 `root` 和一个整数目标和 `targetSum`，判断该树中是否存在**根节点到叶子节点**的路径，使得这条路径上所有节点值相加等于 `targetSum`。

**叶子节点**是指没有子节点的节点。树可能为空。

## 输入格式

第一行：二叉树的层序序列（LeetCode 风格），节点值之间用空格分隔，空节点用 `null` 表示，末尾多余的 `null` 可以省略；如果树为空，这一行只有一个 `null`。
第二行：一个整数 `targetSum`。

## 输出格式

如果存在一条从根节点到叶子节点的路径，其节点值之和等于 `targetSum`，输出 `true`；否则输出 `false`。

## 示例

### 示例 1

输入：
```
5 4 8 11 null 13 4 7 2 null null null 1
22
```

输出：
```
true
```

解释：路径 `5 -> 4 -> 11 -> 2` 的和为 22，满足条件；另一条叶子路径 `5 -> 8 -> 4 -> 1` 的和为 18，不满足。

### 示例 2

输入：
```
1 2 3
5
```

输出：
```
false
```

解释：两条根到叶子的路径 `1 -> 2`（和为 3）和 `1 -> 3`（和为 4）都不等于 5。

### 示例 3

输入：
```
null
1
```

输出：
```
false
```

解释：空树没有任何根到叶子的路径，直接返回 `false`。

## 数据范围

- 树中节点数 `0 <= n <= 5000`
- `-1000 <= Node.val <= 1000`
- `-1000 <= targetSum <= 1000`
