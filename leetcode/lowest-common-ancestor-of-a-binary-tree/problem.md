## 题目描述

给定一个二叉树，找到该树中两个指定节点的最近公共祖先。

最近公共祖先的定义为：「对于有根树 T 的两个节点 p、q，最近公共祖先表示为一个节点 x，满足 x 是 p、q 的祖先且 x 的深度尽可能大（一个节点也可以是它自己的祖先）。」

例如给定如下二叉树 `root = [3,5,1,6,2,0,8,null,null,7,4]`：

```
        3
      /   \
     5     1
    / \   / \
   6   2 0   8
      / \
     7   4
```

## 输入格式

- 第一行一个整数 `n`，表示层序数组（含 `null` 占位）的元素个数；
- 第二行 `n` 个 token，空格分隔，每个 token 是一个整数或 `null`，按层序（LeetCode 习惯）描述一棵二叉树；
- 第三行两个整数 `p` 和 `q`，表示要查询的两个节点的值。

## 输出格式

输出一个整数，表示 `p` 和 `q` 的最近公共祖先节点的值。

## 示例

### 示例 1

输入：
```
11
3 5 1 6 2 0 8 null null 7 4
5 1
```

输出：
```
3
```

解释：节点 5 和节点 1 分别在根节点 3 的左右子树里，所以最近公共祖先是 3。

### 示例 2

输入：
```
11
3 5 1 6 2 0 8 null null 7 4
5 4
```

输出：
```
5
```

解释：节点 5 是节点 4 的祖先，根据定义最近公共祖先可以是节点本身。

## 数据范围

- 树中节点数目在范围 `[2, 10^5]` 内
- `-10^9 <= Node.val <= 10^9`
- 所有 `Node.val` 互不相同
- `p != q`，且 `p`、`q` 均存在于给定的二叉树中
