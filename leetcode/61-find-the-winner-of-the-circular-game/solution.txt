[思路]

倒推（数学归纳）：

- 只剩 1 个人时，获胜者在当前圈里的下标一定是 0；
- 把人数从 i - 1 增加到 i：相当于在长度为 i - 1 的解前面插入一个被删除的人，获胜者的下标变为 (ans + m) % i；
- 于是从 i = 2 递推到 i = n，最后的 ans 是 0 起始编号下的答案，加 1 就是 1 ~ n 的编号。

以示例 1（n = 5, m = 2）为例，逐轮递推：

    i = 1                     ans = 0                  只剩 1 人，下标 0
    i = 2   ans = (0 + 2) % 2 = 0
    i = 3   ans = (0 + 2) % 3 = 2
    i = 4   ans = (2 + 2) % 4 = 0
    i = 5   ans = (0 + 2) % 5 = 2        0 起始编号下的获胜者

    ans + 1 = 3，与 1 ~ n 编号下的答案一致

文档里剑指 Offer 62 的 Java 解法就是这三行：

    int ans = 0;
    for (int i = 2; i <= n; i++) ans = (ans + m) % i;
    return ans;   // 0-based，本题要再 +1

[复杂度]
时间：O(n)（一趟递推）   空间：O(1)

[关键点]

- 递推式 ans = (ans + m) % i 里的 i 是当前人数，从 2 开始到 n
- 本题输出 1 ~ n 的编号，所以最后要 +1；剑指 Offer 62 / 从 0 编号的版本直接输出 ans 即可
- 不要用链表或数组真的模拟每次出圈，那是 O(n * m)，n = 10^5, m = 10^6 时会超时
- m > i 时取模仍然正确（(ans + m) % i 本身就处理了绕圈）
- 中间量用 long long，避免加法溢出

[C++ 代码]
// 找出游戏的获胜者 / 约瑟夫环（LeetCode 1823，同剑指 Offer 62）
// https://leetcode.cn/problems/find-the-winner-of-the-circular-game/
//
// 思路：倒推。只剩 1 人时获胜者下标为 0；把人数从 2 推到 n，
//       每轮 ans = (ans + m) % i，最后换算成 1~n 的编号。
// 复杂度：时间 O(n) 空间 O(1)
#include <iostream>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    long long n, m;
    if (!(cin >> n >> m)) return 0;

    long long ans = 0;  // 0 起始编号下的获胜者下标
    for (long long i = 2; i <= n; ++i) {
        ans = (ans + m) % i;
    }

    cout << ans + 1 << '\n';  // 本题编号是 1~n
    return 0;
}
