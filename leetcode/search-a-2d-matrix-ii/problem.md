## 题目描述

编写一个高效的算法，在一个 `m x n` 的矩阵 `matrix` 中搜索目标值 `target`。该矩阵具有以下特性：

- 每行的元素从左到右升序排列。
- 每列的元素从上到下升序排列。

## 输入格式

第一行两个整数 `m n`，表示矩阵的行数和列数。
接下来 `m` 行，每行 `n` 个整数，表示矩阵。
最后一行一个整数 `target`。

## 输出格式

输出一行：`target` 在矩阵中输出 `true`，否则输出 `false`。

## 示例

### 示例 1

输入：
```
5 5
1 4 7 11 15
2 5 8 12 19
3 6 9 16 22
10 13 14 17 24
18 21 23 26 30
5
```

输出：
```
true
```

解释：`target = 5` 出现在第 2 行第 2 列，返回 `true`。

### 示例 2

输入：
```
5 5
1 4 7 11 15
2 5 8 12 19
3 6 9 16 22
10 13 14 17 24
18 21 23 26 30
20
```

输出：
```
false
```

解释：矩阵中不存在 20，返回 `false`。

### 示例 3

输入：
```
1 1
-5
-5
```

输出：
```
true
```

解释：矩阵只有一个元素，恰好等于 `target`，返回 `true`。

## 数据范围

- `m == matrix.length`，`n == matrix[i].length`
- `1 <= m, n <= 300`
- `-10^9 <= matrix[i][j] <= 10^9`
- 每行的元素从左到右升序排列，每列的元素从上到下升序排列（题目不保证元素互不相同）
- `-10^9 <= target <= 10^9`
