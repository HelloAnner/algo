题目：二叉树的右视图
链接：https://leetcode.cn/problems/binary-tree-right-side-view/
难度：中等

[题目描述]

给定一棵二叉树的根节点 root，想象自己站在它的右侧，按照从顶部到底部的顺序，返回从右侧所能看到的节点值。

（文档 58 节只写了「二叉树右视图」四个字，没有给题面和链接，这里按 LeetCode 199 的标准题意补全。）

[输入格式]

第一行一个整数 n，表示按层序给出的序列长度，0 表示空树。
第二行 n 个 token，用空格分隔，是二叉树的层序遍历序列（LeetCode 的序列化格式）：整数表示节点值，null 表示该位置为空节点，空节点的孩子不再出现在序列里。

[输出格式]

一行，从右侧能看到的节点值，按从顶部到底部的顺序，相邻数字用一个空格分隔。
若树为空（n = 0），输出一个空行。

[示例 1]

输入：
7
1 2 3 null 5 null 4

输出：
1 3 4

解释：这棵树长这样（右边竖线就是你的视线）：

        1
       / \
      2   3
       \   \
        5   4

根节点 1 可见；第二层最右边是 3；第三层最右边是 4（5 被 4 挡住），所以右视图是 1 3 4。

[示例 2]

输入：
3
1 null 3

输出：
1 3

解释：1 的左孩子为空、右孩子是 3，两层各看到一个节点：

      1
       \
        3

[示例 3]

输入：
4
1 2 3 4

输出：
1 3 4

解释：4 是 2 的左孩子，虽然偏左，但它所在的第三层只有它一个节点，所以从右侧依然看得到：

        1
       / \
      2   3
     /
    4

[数据范围]

- 二叉树的节点数在 [0, 100] 内
- -100 <= Node.val <= 100
- 输入保证层序序列合法：null 的位置不会再有孩子 token

[提示]

- 把「层序遍历序列」还原成二叉树时，要注意 null 节点的孩子不会被写进序列（用队列逐个给非空节点分配孩子 token）。
