[思路]
按「位数」分组，一组一组地把 n 减掉：

   位数 d   数字个数 count   这一组占的总位数 d*count
   1        9                9
   2        90               180
   3        900              2700

设当前组的位数是 d、组内第一个数是 start（1、10、100 ...）、数字个数是 count（9、90、900 ...）：

1. 若 n > d * count，说明第 n 位不在这一组：n -= d * count，然后 d++、start *= 10、count *= 10；
2. 否则第 n 位就落在这一组里：
   - 组内第 (n - 1) / d 个数（0-based）就是目标数字 num = start + (n - 1) / d；
   - 它在该数字里从左数第 idx = (n - 1) % d 位：先砍掉右边 d - 1 - idx 位（除以 10^(d-1-idx)），再对 10 取余。

以 n = 11 为例：9 < 11，减去 9 得 n = 2，进入两位数这一组；num = 10 + (2 - 1) / 2 = 10，idx = (2 - 1) % 2 = 1，取 10 从左数第 1 位（0-based）正好是 0。

[复杂度]
时间：O(log n)，最多循环到 18 位数，每组 O(1)
空间：O(1)

[关键点]
- n 用 long long；d * count 也用 long long 算（n <= 10^18 时 d 最多到 17，不会溢出）
- 下标从 1 开始，所以统一先写成 n - 1 再取整 / 取余
- 取第 idx 位是「先右移、再取模」，顺序反了就错了
- 边界：n = 9 输出 9，n = 10 输出 1

[C++ 代码]
// 第 N 位数字（LeetCode 400. Nth Digit）
// https://leetcode.cn/problems/nth-digit/
//
// 思路：按位数分组（1 位数 9 个、2 位数 90 个 ...），先把前面各组占的位数减掉，
//       再在组内定位到具体数字，并从左数取出第 k 位。
// 复杂度：时间 O(log n) 空间 O(1)
#include <iostream>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    long long n;
    if (!(cin >> n)) return 0;

    long long d = 1;      // 当前组的位数：1, 2, 3 ...
    long long start = 1;  // 当前组的第一个数：1, 10, 100 ...
    long long count = 9;  // 当前组数字的个数：9, 90, 900 ...
    while (n > d * count) {
        n -= d * count;
        ++d;
        start *= 10;
        count *= 10;
    }

    long long num = start + (n - 1) / d;  // 第 n 位所在的数字
    int idx = static_cast<int>((n - 1) % d);  // 在该数字中从左数第几位（0-based）

    // 取出 num 从左数第 idx 位：先砍掉右边的 d - 1 - idx 位
    long long p = 1;
    for (int i = 0; i < d - 1 - idx; ++i) p *= 10;

    cout << (num / p) % 10 << '\n';
    return 0;
}
