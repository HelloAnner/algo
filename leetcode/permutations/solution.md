## 思路

回溯（DFS）+ 选择撤销：

- `path` 记录当前已经选的数，`used[i]` 记录 `nums[i]` 有没有被用过；
- 每一层从前往后尝试所有没用过的数：选一个 → 递归 → 回来把它撤销；
- `path` 的长度等于 `n` 时输出一个排列。

文档第 81 题这一节没有给代码（只写了「没有题目」），但这就是全排列的标准解法。C++ 里也可以用 `sort + next_permutation` 循环输出，本质是同一套思路，代码更短。

## 复杂度

- 时间：O(n * n!)，一共 `n!` 个排列，每个排列输出要 O(n)
- 空间：O(n)，递归深度 `n`，加上 `used` / `path` 数组（不含输出本身）

## 关键点

- **输出顺序**：LeetCode 只要求「所有排列」，顺序任意；为了能逐行对拍，这里先把输入排序，再按升序尝试，输出就天然是字典序
- 回溯要成对出现：进入时 `used[i] = true` 并 `push_back`，递归返回后立刻还原
- 本题元素互不相同，不用去重；如果元素可重复（LC 47），要先排序并在同一层跳过相同的值
- `n` 最大只有 6，`n!` 增长极快，注意输出量
