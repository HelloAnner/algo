[思路]

标准二分：用左闭右开区间 [lo, hi) 找「第一个大于等于 target 的位置」，也就是 C++ 的 lower_bound。

    lo = 0, hi = n;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (nums[mid] < target) lo = mid + 1;  // mid 及其左边都小于 target，答案在右半
        else                    hi = mid;      // nums[mid] >= target，mid 本身可能就是答案
    }

循环结束时 lo == hi，它就是第一个 >= target 的下标。最后再检查 lo < n && nums[lo] == target：成立就输出 lo，否则说明数组中不存在 target，输出 -1。

为什么对：循环不变式是「第一个 >= target 的位置始终落在 [lo, hi] 内」。nums[mid] < target 时，mid 和它左边的元素都小于 target，可以把 lo 推到 mid + 1；nums[mid] >= target 时，mid 自身仍是候选，所以 hi = mid 而不是 mid - 1。区间每次至少缩小一半，因此 O(log n) 收敛。

关于「在链表中怎么做二分查找」：链表不支持 O(1) 随机访问，直接二分没有意义——每次取中点都要 O(n) 走一遍，总复杂度反而退化。工程上的答案是跳表（skip list）：在有序链表之上建多级索引，每一级按固定概率（比如 1/2）从下一级抽样出节点；查找时从最高层索引开始向右走，走不动就下降一层。期望查找 / 插入 / 删除都是 O(log n)，空间 O(n)，Redis 的 zset 就是这么实现的。文档里说的「再加一个链表，节点有 next 和 main 两个指针，每两个主链表节点抽一个索引节点」，描述的就是跳表的思想。

[复杂度]
时间：O(log n)   空间：O(1)（除输入数组外）

[关键点]
- mid = lo + (hi - lo) / 2，不要写 (lo + hi) / 2（下标很大时会溢出）
- 区间开闭和更新方式必须配套：[lo, hi) 配 while (lo < hi) 与 hi = mid；若写成闭区间 [lo, hi]，那就要 hi = mid - 1
- 要「第一次出现的位置」，判断必须写成 nums[mid] < target 走左分支，等价于求 lower_bound；写成 <= 会返回最后一次出现的位置
- 循环结束后要用 lo < n && nums[lo] == target 确认命中，不能直接输出 lo
- 数值范围到 10^9，nums 和 target 用 long long 更保险
- n = 0 的退化输入要输出 -1

[C++ 代码]
// 手写二分查找
// https://leetcode.cn/problems/binary-search/
//
// 思路：在升序数组上用左闭右开区间 [lo, hi) 二分，找第一个 >= target 的位置，再确认是否命中。
// 复杂度：时间 O(log n) 空间 O(1)
#include <iostream>
#include <vector>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n = 0;
    if (!(cin >> n) || n <= 0) {
        cout << -1 << '\n';
        return 0;
    }

    vector<long long> nums(n);
    for (auto &x : nums) cin >> x;

    long long target = 0;
    cin >> target;

    int lo = 0, hi = n;  // 左闭右开 [lo, hi)
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (nums[mid] < target) {
            lo = mid + 1;
        } else {
            hi = mid;
        }
    }

    if (lo < n && nums[static_cast<size_t>(lo)] == target) cout << lo << '\n';
    else cout << -1 << '\n';
    return 0;
}
