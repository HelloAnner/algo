## 题目描述

手写快速排序：给定一个整数数组，把它按**升序**排序后输出。不允许调用库排序函数（如 `std::sort`），必须自己实现快排。

快排是分治思想：选一个基准元素（pivot），把数组划分成「不大于基准」和「不小于基准」两部分，使基准归位，再对左右两部分递归排序，最终整体有序。实现上通常用**头尾双指针**完成一趟划分。

## 输入格式

- 第一行一个整数 `n`，表示数组长度；
- 第二行 `n` 个整数 `a[0..n-1]`，相邻数字用空格分隔。

## 输出格式

一行，`n` 个整数，按升序排列，相邻数字用空格分隔。

## 示例

### 示例 1

输入：
```
5
5 2 9 1 5
```

输出：
```
1 2 5 5 9
```

解释：含重复元素 5，排序后两个 5 相邻；重复元素不需要稳定，位置可以互换。

### 示例 2

输入：
```
6
3 3 3 1 2 0
```

输出：
```
0 1 2 3 3 3
```

解释：大量重复元素是快排最容易退化的场景之一，实现时要保证划分仍然均衡。

## 数据范围

- `1 <= n <= 5 * 10^4`
- `-5 * 10^4 <= a[i] <= 5 * 10^4`
- 要求平均（期望）时间复杂度 `O(n log n)`，额外空间 `O(log n)` 递归栈
