[思路]

快排 =「分治 + 划分」。核心是 partition：在 [low, high] 内选一个基准值 pivot，把区间整理成「左边都小于 pivot、右边都大于 pivot」，并返回分界位置，然后递归处理分出来的两段。

这里采用头尾双指针（Hoare 划分），和文档里 Java 代码是同一思路，只是内层循环的比较符改成严格不等：

    int partition(vector<int>& arr, int low, int high) {
        int pivot = arr[low + rng() % (high - low + 1)];  // 随机基准
        int i = low - 1, j = high + 1;
        while (true) {
            do { ++i; } while (arr[i] < pivot);   // 从左找第一个不小于 pivot 的
            do { --j; } while (arr[j] > pivot);   // 从右找第一个不大于 pivot 的
            if (i >= j) return j;                 // 两指针相遇，划分结束
            swap(arr[i], arr[j]);
        }
    }

一趟划分结束时返回的 j 保证 j < high，于是递归 [low, j] 与 [j+1, high] 就能不重不漏地覆盖整个区间（这也是 Hoare 划分不用把 pivot 单独换到中间的原因）。

为什么比较符要用严格的不等号？文档里的写法是 while (pivot <= arr[j]) j-- 和 while (pivot >= arr[i]) i++，遇到「整个数组都是相同元素」时，两指针会一路贴到一起，划分点始终落在区间端点，退化成 O(n^2)、递归深度 O(n)（示例 2 就是这种数据）。改成 < / > 后，相等的元素会被分到两侧、划分保持均衡，重复元素多时依然是 O(n log n)（这就是所谓「等于基准的元素也要停下来交换」的技巧）。

另一种同样稳的做法是三路划分：把区间分成小于 pivot、等于 pivot、大于 pivot 三段，只递归前后两段，重复元素多时甚至更快。

[复杂度]
时间：平均 / 期望 O(n log n)，随机基准下退化到 O(n^2) 的概率极低   空间：O(log n) 递归栈（原地排序，不额外开数组）

[关键点]
- 随机基准：固定取 arr[low] 时，已排序数组会退化到 O(n^2)，必须随机（或三数取中）
- 内层循环的边界保护：这里用「i 从 low-1 起、j 从 high+1 起 + do/while」的写法，因为基准值本身一定在区间内，指针最多停在基准元素上，不会越界
- 递归终止条件 low >= high，写成 low > high 时对单元素区间会多做一次无意义调用
- 相等元素不能跳过：内层用 <= / >= 会让全等数组退化（见上）
- 快排不稳定，题目只要求升序，无需保证相等元素的相对次序
- int 足够：元素值在 ±5 * 10^4 内

[C++ 代码]
// 手写快速排序
// https://leetcode.cn/problems/sort-an-array/
//
// 思路：分治 + Hoare 头尾双指针划分，随机选基准避免有序数据退化；相等元素也停下来交换以保持划分均衡。
// 复杂度：期望时间 O(n log n) 空间 O(log n)（递归栈）
#include <chrono>
#include <iostream>
#include <random>
#include <utility>
#include <vector>

using namespace std;

mt19937 rng(static_cast<unsigned>(chrono::steady_clock::now().time_since_epoch().count()));

// 头尾双指针划分：返回分界点 j，保证 [low, j] 与 [j+1, high] 各自有序化后整体有序
int partitionRange(vector<int> &arr, int low, int high) {
    int pivot = arr[low + static_cast<int>(rng() % static_cast<unsigned>(high - low + 1))];
    int i = low - 1;
    int j = high + 1;
    while (true) {
        do { ++i; } while (arr[i] < pivot);
        do { --j; } while (arr[j] > pivot);
        if (i >= j) return j;
        swap(arr[i], arr[j]);
    }
}

void quickSort(vector<int> &arr, int low, int high) {
    if (low >= high) return;
    int mid = partitionRange(arr, low, high);
    quickSort(arr, low, mid);
    quickSort(arr, mid + 1, high);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    if (!(cin >> n)) return 0;
    vector<int> arr(n);
    for (int &x : arr) cin >> x;

    quickSort(arr, 0, n - 1);

    for (int i = 0; i < n; ++i) {
        if (i > 0) cout << ' ';
        cout << arr[i];
    }
    cout << '\n';
    return 0;
}
