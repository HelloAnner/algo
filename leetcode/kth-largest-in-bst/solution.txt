[思路]

二叉排序树的基本性质：中序遍历（左 -> 根 -> 右）得到的是递增序列。（文档里写的「前序遍历时递增」是笔误，前序不满足这个性质。）

所以「第 k 大」就是中序遍历序列的倒数第 k 个元素。更省事的做法是直接做逆向中序遍历（右 -> 根 -> 左），也就是从最大的节点开始依次访问，边走边计数，访问到第 k 个就立刻返回——既不用存下整个序列，也能提前结束。

实现分两步：

1. 建树：按插入顺序，从根开始比较，小就往左走、大就往右走，走到空位挂上去。用 val / leftChild / rightChild 三个数组存树（下标即节点编号，-1 表示空），比指针更省事也更快。
2. 逆向中序（迭代）：用一个显式栈。先把当前节点以及它的一路右孩子全部压栈；弹出栈顶访问（计数 +1），若计数到 k 就输出并结束；否则转向它的左孩子继续。

遍历示意（示例 1 的树）：

              5
            /   \
           3     8
          / \
         1   4

    逆中序访问顺序：8 -> 5 -> 4 -> 3 -> 1（严格递减），第 2 次访问到的 5 就是答案

为什么对：逆中序遍历访问的正是「右子树 -> 根 -> 左子树」，而右子树里的值都大于根、左子树里的值都小于根，所以访问序列严格递减，第 k 次访问到的就是第 k 大的元素。

为什么用迭代：如果插入顺序恰好是升序（或降序），二叉排序树会退化成一条长度为 n 的链，递归遍历的调用栈深度会达到 10^5，容易爆栈；显式栈没有这个问题。

[复杂度]

时间：建树平均 O(n log n)，最坏 O(n^2)（升序/降序插入会退化成一条链，每次插入都要走到链尾）；逆中序遍历 O(n)，实际数到第 k 个就提前结束。   空间：O(n) 存树（三个数组），遍历的显式栈 O(h)，h 为树高（最坏 O(n)）。

关于数据范围：本题数据范围取 n <= 2 * 10^4，正是为了让「退化链」这种最坏情况（约 2 * 10^8 次比较）也能跑过。如果要支持 10^5 量级，有两个选择：把输入排序后用「取中点递归建树」的方式建一棵平衡二叉排序树（中序序列不变，第 k 大也不变），或者干脆排序后取第 k 大——但后者就没用到二叉排序树的性质了。

[关键点]

- 文档说的「前序遍历递增」是笔误，只有中序遍历才递增
- 「第 k 大」用逆中序（右 -> 根 -> 左），不要写成正序后再从数组尾部找（多存一个数组，也没提前退出）
- 计数到 k 要立刻退出循环，别继续把整棵树走完
- 退化链时递归会爆栈，用显式栈迭代
- 节点值可能有负数、也可能到 10^9，用 int 存值没问题，但不要用 -1 之类的哨兵值表示空节点（用单独的下标 -1 表示空即可）
- 题目保证节点值互不相同，所以插入时不用考虑相等的情况

[C++ 代码]
// 二叉排序树中第 k 大的元素（文档 69 节，非 LeetCode 原题）
// （《手撕字节跳动面试时出现过的算法题》69：利用二叉排序树的性质找第 k 大的元素）
//
// 思路：按插入顺序建 BST，再对它做「右-根-左」的逆中序遍历，第 k 个访问到的就是答案（迭代实现，防退化树爆栈）。
// 复杂度：时间 建树最坏 O(n^2) / 遍历 O(n)，空间 O(n)
#include <iostream>
#include <vector>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, k;
    cin >> n >> k;

    // 数组存树：下标即节点编号，-1 表示空孩子；0 号节点是根
    vector<int> val(n, 0), leftChild(n, -1), rightChild(n, -1);
    cin >> val[0];
    for (int i = 1; i < n; ++i) {
        cin >> val[i];
        int cur = 0;
        while (true) {  // 从根一路比较，找到空位挂上去
            if (val[i] < val[cur]) {
                if (leftChild[cur] == -1) {
                    leftChild[cur] = i;
                    break;
                }
                cur = leftChild[cur];
            } else {
                if (rightChild[cur] == -1) {
                    rightChild[cur] = i;
                    break;
                }
                cur = rightChild[cur];
            }
        }
    }

    // 逆中序遍历：右 -> 根 -> 左，从最大的元素开始数
    vector<int> stk;
    int cur = 0, cnt = 0, ans = val[0];
    while (cur != -1 || !stk.empty()) {
        while (cur != -1) {  // 一路向右，右子树里的值都更大
            stk.push_back(cur);
            cur = rightChild[cur];
        }
        cur = stk.back();
        stk.pop_back();
        if (++cnt == k) {  // 第 k 个访问到的就是第 k 大
            ans = val[cur];
            break;
        }
        cur = leftChild[cur];
    }

    cout << ans << '\n';
    return 0;
}
