[思路]

分桶（计数排序）+ 后缀和：

1. 读入成绩时不保存原数组，直接 cnt[score]++，O(n) 统计出每个分数有多少人；
2. 从 750 往 0 扫，维护变量 higher 表示「分数严格大于当前分数的人数」：对每个分数 s，先记录 rank[s] = higher + 1，再执行 higher += cnt[s]（把自己这一批人算进更小分数的「前面的人数」）；
3. 每个询问 O(1) 查表，输出 rank[s] 和 cnt[s]。

  分数   750   749   ...   650   ...   600   ...    0
        +-----+-----+-----+-----+-----+-----+-----+-----+
  人数  |  0  |  0  | ... |  1  | ... |  1  | ... |  0  |
        +-----+-----+-----+-----+-----+-----+-----+-----+
  扫描  <---------------------------------------------  从高到低

  higher 的变化（示例 1：600 700 700 500 650）：
    s = 750..701  cnt = 0    higher = 0    rank = 1
    s = 700       cnt = 2    rank = 0 + 1 = 1，然后 higher = 2
    s = 699..651  cnt = 0    higher = 2    rank = 3
    s = 650       cnt = 1    rank = 2 + 1 = 3，然后 higher = 3
    s = 649..601  cnt = 0    higher = 3    rank = 4
    s = 600       cnt = 1    rank = 3 + 1 = 4，然后 higher = 4
    s = 599..0    cnt = 0    higher = 4    rank = 5

正确性：higher 在扫描到 s 时恰好是「分数 > s 的人数」，所以 higher + 1 就是并列取最好名次时的排名；cnt[s] 是人数。分数范围固定为 0 ~ 750，751 个桶足以覆盖全部取值。

文档里的原始思路是「按 0-150、151-300、…、601-750 分五个区间分桶，区间内再细分」。这其实就是分桶排序的粗粒度版本：先定位区间、再在区间内精确定位。因为分数只有 751 种取值，直接「一个分数一个桶」最简单，复杂度同样是 O(n + 751 + q)；只有分数范围非常大（比如 1 到 10^9）时，才需要退化成「区间桶 + 桶内排序」。

[复杂度]
时间：O(n + 751 + q)（读入 O(n)，预处理 O(751)，每次询问 O(1)）   空间：O(751)（成绩边读边统计，不需要存下 2000 万条数据）

[关键点]

- 并列取最好名次：rank = 严格大于 s 的人数 + 1，所以必须先记录 rank[s] 再累加 cnt[s]，顺序反了会把自己这一批算成「更高分」
- 必须从高到低扫才能得到后缀和；从低到高得到的是「严格小于」的人数
- 询问的分数可以没人考过：此时 cnt = 0，而 rank 仍由后缀和给出（750 分在没人满分时排第 1，0 分在没人零分时排 n + 1）
- 人数用 long long，n 可达 2 * 10^7，int 虽然够但不值得冒险
- 输入量很大，cin 必须关同步（ios::sync_with_stdio(false); cin.tie(nullptr);），否则 2000 万次读入会超时
- 本题是「在线回答大量询问」的经典模型：预处理一次，询问 O(1)

[C++ 代码]
// 找范围（高考成绩分桶排名）
// https://www.nowcoder.com/discuss/425581
//
// 思路：分数只有 0~750，按分数分桶计数，再从高到低求后缀和得到每个分数的排名。
// 复杂度：时间 O(n + 751 + q) 空间 O(751)
#include <iostream>
#include <vector>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    long long n, q;
    if (!(cin >> n >> q)) return 0;

    const int MAXS = 750;
    vector<long long> cnt(MAXS + 1, 0);
    for (long long i = 0; i < n; ++i) {
        int s;
        cin >> s;
        if (s < 0) s = 0;
        if (s > MAXS) s = MAXS;
        ++cnt[s];
    }

    // rankOf[s] = 严格高于 s 的人数 + 1（从高到低求后缀和）
    vector<long long> rankOf(MAXS + 1, 1);
    long long higher = 0;
    for (int s = MAXS; s >= 0; --s) {
        rankOf[s] = higher + 1;
        higher += cnt[s];
    }

    for (long long k = 0; k < q; ++k) {
        int s;
        cin >> s;
        cout << rankOf[s] << ' ' << cnt[s] << '\n';
    }
    return 0;
}
