题目：找范围
链接：https://www.nowcoder.com/discuss/425581
难度：中等

[题目描述]

高考成绩有 N 条记录，分数是 0 ~ 750 的整数。要求快速回答任意分数的排名：

- 给定一个分数 s，输出 s 的排名 rank：分数严格大于 s 的人数 + 1（并列取最好名次，即并列同名次）；
- 同时输出考到 s 分的人数 cnt。

分数种类只有 751 种，远小于人数（可达 2000 万），正解是分桶 + 后缀和（计数排序的思想）：读入时把每个分数的人数统计进桶，再从高到低求后缀和，就能 O(1) 回答每次询问。

一个分数一个桶，桶里只存人数；排名 = 比它高的所有桶的人数之和 + 1：

   分数   750   749   ...   650   ...   600   ...    0
         +-----+-----+-----+-----+-----+-----+-----+-----+
   人数  |  0  |  0  | ... |  1  | ... |  1  | ... |  0  |
         +-----+-----+-----+-----+-----+-----+-----+-----+
                             ^
                             s = 650（示例 1：700 分 2 人、650 分 1 人、600 分 1 人）
        rank[650] = 严格高于 650 的人数 + 1 = 2 + 1 = 3
        cnt[650]  = 桶里的值 = 1

   从 750 往 0 扫，边扫边维护 higher（更高分的人数）：
   扫到 s 时先记下 rank[s] = higher + 1，再把 cnt[s] 累加进 higher。

[输入格式]

第一行两个整数 n 和 q，分别表示成绩条数和询问个数。
第二行 n 个整数，表示每条成绩（0 <= 分数 <= 750），相邻数字用空格分隔。
接下来 q 行，每行一个整数 s，表示一次询问的分数（0 <= s <= 750）。

[输出格式]

共 q 行，每行两个整数 rank cnt，用空格分隔：
rank 是分数 s 的排名（严格高于 s 的人数 + 1），cnt 是恰好考 s 分的人数。
若没有任何人考到 s 分，cnt = 0，rank 仍然表示「考了这个分数会排第几」。

[示例 1]
输入：
5 3
600 700 700 500 650
700
650
600
输出：
1 2
3 1
4 1
解释：成绩从高到低是 700, 700, 650, 600, 500。700 分有 2 人并列第 1；650 分前面有 2 人，排第 3；600 分前面有 3 人，排第 4。

[示例 2]
输入：
5 2
600 700 700 500 650
750
0
输出：
1 0
6 0
解释：没人考 750 分，750 分会排在所有人前面，第 1 名；没人考 0 分，0 分排在 5 人之后，第 6 名。

[示例 3]
输入：
3 2
750 750 0
750
1
输出：
1 2
3 0
解释：两个 750 分并列第 1；1 分前面有 2 人（两个 750），排第 3。

[数据范围]

- 1 <= n <= 2 * 10^7（本仓库样例用较小数据，算法按这个量级设计）
- 1 <= q <= 10^5
- 0 <= 分数 <= 750
