ALGO · 数组 LEETCODE 42

接雨水

trapping-rain-water — 每根柱子的水量 = min(左最高, 右最高) − 自身高度

困难 数组 双指针 单调栈

01题目

给定 n 个非负整数表示宽度为 1 的柱子高度图，计算下雨后能接多少水。

输入：height = [0,1,0,2,1,0,1,3,2,1,2,1] 输出：6
核心洞察 按列看：第 i 根柱子上方能接的水 = min(左边最高, 右边最高) − height[i]（短板效应）。所有解法都是围绕"怎么更快地拿到左右最高"展开：预处理数组、双指针、单调栈。

02思路演进

按列暴力：对每列向左扫最高、向右扫最高，O(n²)。正确性显然，但左右最高被重复计算了 n 遍。

动态规划：左右最高只依赖单调方向的累计——L[i]=max(L[i-1],h[i])、R[i]=max(R[i+1],h[i])，两遍预处理 O(n)，再一遍求和。空间 O(n)。

双指针压空间：谁矮谁先结算——若 h[l] < h[r]，则 l 处的右最高至少不低于左最高，l 的水量只由左最高决定，结算后 l++。两个滚动最大值替代两个数组，O(1) 空间。

单调栈视角：按行接水——栈存递减柱高，遇高柱出栈形成凹槽，水量按 (宽 × 凹槽高) 横向累加。同一问题的横切视角，理解单调栈的最佳题。

05单调栈：横着看同一道题

双指针是竖着一列列结算；单调栈是横着一层层结算。维护一个高度单调递减的下标栈；遇到比栈顶高的柱子，栈顶就是凹槽底，出栈，凹槽的左右墙分别是新栈顶和当前柱子，水量 += 宽 × (min(两墙) − 槽底)。

单调栈的通用语义：找每个元素"两侧第一个比它大/小的元素"。接雨水找的是"两侧更高墙"，所以用递减栈。同类题：LC 84（柱状图最大矩形，递增栈）、LC 739（每日温度）、LC 503（下一个更大元素 II）。

06代码实现

def trap(height):
    # 每列向左右扫最高，O(n²)，理解题意的起点
    ans = 0
    for i in range(1, len(height) - 1):
        l = max(height[:i+1]); r = max(height[i:])
        ans += min(l, r) - height[i]
    return ans
def trap(height):
    # 预处理左右最高数组，O(n) / O(n)
    n = len(height)
    L, R = [0]*n, [0]*n
    for i in range(1, n): L[i] = max(L[i-1], height[i-1])
    for i in range(n-2, -1, -1): R[i] = max(R[i+1], height[i+1])
    return sum(max(0, min(L[i], R[i]) - height[i]) for i in range(n))
def trap(height):
    # 递减栈，遇高柱结算凹槽（横向一层层算）
    st, ans = [], 0
    for i, h in enumerate(height):
        while st and height[st[-1]] < h:
            bottom = height[st.pop()]
            if not st: break      # 没有左墙
            w = i - st[-1] - 1
            ans += w * (min(height[st[-1]], h) - bottom)
        st.append(i)
    return ans
def trap(height):
    # 谁矮谁先结算，O(n) / O(1)
    l, r = 0, len(height) - 1
    l_max = r_max = ans = 0
    while l < r:
        if height[l] < height[r]:
            if height[l] >= l_max: l_max = height[l]
            else: ans += l_max - height[l]   # 右侧必有更高的墙
            l += 1
        else:
            if height[r] >= r_max: r_max = height[r]
            else: ans += r_max - height[r]
            r -= 1
    return ans

双指针正确性的关键一句：当 height[l] < height[r]，l 右侧至少有一堵比 lMax 高的墙，所以 l 处水量由 lMax 单方面决定，可以立即结算——不需要知道真实的右最高是多少。

07复杂度对比

解法时间空间说明
按列暴力O(n²)O(1)左右最高重复扫
动态规划O(n)O(n)预处理左右最高，最好写
单调栈O(n)O(n)横向结算，单调栈经典题
双指针O(n)O(1)谁矮先算，最优交付版

08边界、坑与变体

  • 长度 < 3：不可能存水，循环不进入，返回 0。
  • 严格递增/递减序列：一端没墙，每个位置水量都是 0，正确。
  • 双指针相等时：height[l] == height[r] 走哪边都行，代码里归到 else（结算右侧），不影响正确性。
  • 变体 → LC 84（柱状图最大矩形）：同一批"两侧边界"思想，递增单调栈。
  • 变体 → LC 407（接雨水 II）：二维版，用最小堆从外圈向里收缩，难度跳档。
