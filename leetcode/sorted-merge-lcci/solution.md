## 思路

双指针**从后往前**归并（原地完成，不额外开数组）：

- `i = m - 1` 指向 `A` 有效元素的末尾，`j = n - 1` 指向 `B` 的末尾，`k = m + n - 1` 指向 `A` 的写入位置；
- 每次比较 `A[i]` 与 `B[j]`，把**较大**的那个写到 `A[k]`，对应指针前移，`k` 前移；
- 某个数组先走完后，把另一个数组剩下的元素依次填到 `A` 前面。

正确性：写入位置满足 `k >= max(i, j)`，所以从后往前写永远不会覆盖还没参与比较的元素；每一步取的都是两个剩余序列当前最大值的较大者，因此填充出来的序列非递减，正是两个有序数组的归并结果。

文档还给了（1）把 `B` 直接追加到 `A` 尾部再整体排序，时间 O((m+n)log(m+n))，代码最短但不是最优解；面试时建议写从后往前的双指针，这才是本题的考点。

## 复杂度

- 时间：O(m + n)，每个元素只被写入一次
- 空间：O(1)，原地归并且不需要新数组

## 关键点

- **必须从后往前**：从前往后会在写入时覆盖 `A` 中还没比较的元素
- 收尾别忘了：一个指针走完后另一个数组的剩余部分要原样搬过去（指针本身已经指向正确位置）
- `m == 0` 或 `n == 0` 时循环体一次都不进，收尾循环天然覆盖
- `A[i] == B[j]` 时先取谁都对；先取 `B[j]` 可以让相等元素保持「`A` 在前」的相对顺序
- `m == n == 0` 时输出一个空行，`cout << '\n'` 即可
