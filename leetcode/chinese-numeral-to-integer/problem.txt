题目：中文数字转阿拉伯数字
链接：
难度：中等

[题目描述]

给定一个中文数字字符串，把它转换成对应的阿拉伯数字（整数）。

例如：「一千零二十」→ 1020，「两万三千」→ 23000。

支持的写法：

    类别        字符                            含义
    数字        零 / 〇                         0（只作占位，不参与计算）
    数字        一 二 两 三 四 五 六 七 八 九     1、2（两 同 二）、3 … 9
    小节单位    十 百 千                        10、100、1000
    大节单位    万                              10^4
    大节单位    亿                              10^8
    符号        负                              前缀，表示负数

- 省略写法：十 单独出现表示 10，十二 表示 12，二十 表示 20（十 前面没有数字时按 1 处理）；
- 不支持：大写金额（壹贰叁…）、小数或口语量词（点、块、个），输入中不会出现。

[输入格式]

一行，一个中文数字字符串（UTF-8 编码，可能带首尾空白）。

[输出格式]

一行，一个整数，即转换结果。

[示例 1]

输入：
一千零二十

输出：
1020

解释：1 × 1000 + 2 × 10 = 1020；中间的「零」只是占位符，不参与计算。

[示例 2]

输入：
两万三千

输出：
23000

解释：「两」等于 2，2 × 10000 + 3 × 1000 = 23000。

[示例 3]

输入：
十二

输出：
12

解释：「十」前面没有数字，按 1 × 10 处理，所以是 12 而不是 2。

[示例 4]

输入：
一亿零五百万

输出：
105000000

解释：1 × 10^8 + 5 × 100 × 10^4 = 100000000 + 5000000 = 105000000。逐字拆开看：

    一   亿   零   五   百   万
    |    |    |    |    |    |
    |    |    |    |    +---- 万：把这一节（五百）= 500 乘上 10^4
    |    |    |    +--------- 百：5 × 100 = 500
    |    |    +-------------- 零：占位符，跳过
    |    +------------------- 亿：把前面攒下的整体乘 10^8
    +------------------------ 一：1

[数据范围]

- 字符串长度（按字符计）1 <= |s| <= 32
- 转换结果保证在 [-10^15, 10^15] 之内，需要用 long long
- 输入只包含上表中的字符，以及可能的首尾空白
