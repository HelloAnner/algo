## 题目描述

给定 `n` 个非负整数，表示每个宽度为 1 的柱子的高度图。计算按此排列的柱子，下雨之后能接多少雨水。

雨水只会积在「左右两边都有更高的柱子挡住」的凹槽里，每个位置 `i` 上方能接的水量为
`min(左侧最高柱子, 右侧最高柱子) - height[i]`（负值记为 0）。

## 输入格式

第一行一个整数 `n`，表示柱子的数量。
第二行 `n` 个非负整数 `height[0..n-1]`，相邻数字用空格分隔。

## 输出格式

输出一个整数，表示能接的雨水总量。

## 示例

### 示例 1

输入：
```
12
0 1 0 2 1 0 1 3 2 1 2 1
```

输出：
```
6
```

解释：高度图由数组 `[0,1,0,2,1,0,1,3,2,1,2,1]` 表示，这种情况下可以接 6 个单位的雨水。

### 示例 2

输入：
```
6
4 2 0 3 2 5
```

输出：
```
9
```

解释：下标 1、2、3、4 处分别能接 `2、4、1、2` 个单位（左右最高分别是 4 和 5），合计 9。

### 示例 3

输入：
```
3
4 2 3
```

输出：
```
1
```

解释：只有下标 1 处是一个凹槽，能接 `min(4, 3) - 2 = 1` 个单位。

## 数据范围

- `1 <= n <= 2 * 10^4`
- `0 <= height[i] <= 10^5`
- 结果可能达到 `2 * 10^9` 量级，建议用 `long long` 累加
