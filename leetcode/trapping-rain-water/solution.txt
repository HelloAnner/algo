[思路]
最朴素的写法（文档方法 1）是对每个位置 i 分别向左、向右扫一遍求最大值，时间 O(n²)；文档方法 2 用两个数组预处理出「前缀最大值」和「后缀最大值」，把单点水位变成 O(1) 查询，时间 O(n)、空间 O(n)。这里给出双指针的 O(n) 时间 / O(1) 额外空间写法（也就是文档里「有空再弄」的方法 4）：

维护 left = 0、right = n - 1，以及当前已经扫过的左半边的最大值 leftMax、右半边的最大值 rightMax：

- 若 height[left] < height[right]：此时可以确定 left 处的水位就是 leftMax（见下方说明），于是 ans += leftMax - height[left]，再更新 leftMax，然后 ++left；
- 否则对称地处理 right：ans += rightMax - height[right]，更新 rightMax，然后 --right。

两个指针从两端往中间收缩：

    left ->                                                          <- right
    +----+----+----+----+----+----+----+----+----+----+----+----+
    |  0 |  1 |  0 |  2 |  1 |  0 |  1 |  3 |  2 |  1 |  2 |  1 |
    +----+----+----+----+----+----+----+----+----+----+----+----+
      ^                                                              ^
    leftMax 从左往右扫过的最大值                  rightMax 从右往左扫过的最大值

    每次只结算较矮的一侧：那边挡板更矮，水位已经被它自己那一侧的最大值决定

为什么可以这么算：位置 i 的水位等于 min(左前缀最大, 右后缀最大) - height[i]。当 height[left] < height[right] 时，left 右边一定存在一根不低于它的柱子（至少有 height[right]），并且可以归纳证明「已经扫过的左侧最大值 leftMax 不会超过 left 右侧的真实最大值」——因为 left 指针每次移动的前提都是「当前高度严格小于当时右指针的高度」，而那根更高的柱子始终留在 left 的右侧。所以此时 min(左前缀最大, 右后缀最大) = leftMax，直接结算 left 是安全的，不需要知道右边的真实最大值。

如果觉得双指针的不变量不好讲，用「前缀最大值 + 后缀最大值」两个数组的写法（文档方法 2）更好证明，复杂度 O(n) / O(n)；文档方法 3 的单调栈也能做，思路是「栈里维护递减的高度下标，遇到更高的柱子就结算栈顶那个凹槽」，时间同样是 O(n)。

[复杂度]
时间：O(n)，双指针各扫一遍，每个位置只结算一次
空间：O(1)（除去输入的 height 数组本身；前缀/后缀数组写法是 O(n)）

[关键点]
- 水位公式是 min(leftMax, rightMax) - height[i]，两个最大值都包含 i 自己，这样差值天然非负，不用额外判负
- 双指针只能移动较矮的一侧，移动较高的一侧就错了
- 结果是累加量，最大可达 2 * 10^9，用 int 有溢出风险，建议 long long
- 单调栈写法要注意弹栈后栈空时直接 break（左边没有挡板，接不住水）
- n = 1 或单调上升/下降的柱子，答案都是 0，可以作为自测用例

[C++ 代码]
// 接雨水
// https://leetcode.cn/problems/trapping-rain-water/
//
// 思路：双指针。每次结算较矮的一侧：该侧水位已由它自己的前缀/后缀最大值确定。
// 复杂度：时间 O(n) 空间 O(1)
#include <algorithm>
#include <iostream>
#include <vector>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    if (!(cin >> n) || n <= 0) {
        cout << 0 << '\n';
        return 0;
    }

    vector<long long> h(n);
    for (auto &x : h) cin >> x;

    long long ans = 0;
    int left = 0, right = n - 1;
    long long leftMax = 0, rightMax = 0;  // 0 是合法下界（高度非负）

    while (left < right) {
        if (h[left] < h[right]) {
            leftMax = max(leftMax, h[left]);   // 先更新前缀最大，再结算
            ans += leftMax - h[left];
            ++left;
        } else {
            rightMax = max(rightMax, h[right]);
            ans += rightMax - h[right];
            --right;
        }
    }

    cout << ans << '\n';
    return 0;
}
