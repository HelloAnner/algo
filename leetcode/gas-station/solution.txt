[思路]

一次遍历的贪心：

- total：所有 gas[i] - cost[i] 的总和。如果 total < 0，油的总量都不够跑一圈，直接返回 -1；
- curr：从当前候选起点出发、开到当前位置剩下的油；
- start：当前候选起点的下标。

遍历时 curr += gas[i] - cost[i]。一旦 curr < 0，说明从 start 到 i 之间的任何一个站出发都到不了 i + 1（因为从中间出发剩下的油只会更少），于是把起点改成 i + 1，并把 curr 清零重新累计。

[复杂度]
时间：O(n)，一趟扫描   空间：O(1)

[关键点]
- 无解的充要条件是总油量小于总消耗：total < 0
- curr < 0 时，起点可以直接跳到 i + 1，不需要回退（这是省掉 O(n^2) 暴力的关键）
- 起点可能停在 n，但此时一定有 total < 0，所以最终用 total >= 0 ? start : -1 收口
- gas[i] - cost[i] 可能累加得比较大，用 long long 更稳
- 有解时答案唯一，不需要考虑多个起点

[C++ 代码]
// 加油站（LeetCode 134. Gas Station）
// https://leetcode.cn/problems/gas-station/
//
// 思路：一次遍历。total 记录总盈余，小于 0 一定无解；curr 记录从当前候选起点
//       出发的剩余油量，一旦 curr < 0，说明 start..i 都不能作为起点，改为 i + 1。
// 复杂度：时间 O(n) 空间 O(1)
#include <iostream>
#include <vector>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    if (!(cin >> n)) return 0;

    vector<long long> gas(n), cost(n);
    for (auto &g : gas) cin >> g;
    for (auto &c : cost) cin >> c;

    long long total = 0;  // 总盈余
    long long curr = 0;   // 从 start 出发到当前位置的剩余油量
    int start = 0;
    for (int i = 0; i < n; ++i) {
        long long diff = gas[i] - cost[i];
        total += diff;
        curr += diff;
        if (curr < 0) {
            // 从 start 到 i 之间的站都到不了 i + 1，下一个候选起点是 i + 1
            start = i + 1;
            curr = 0;
        }
    }

    cout << (total >= 0 ? start : -1) << '\n';
    return 0;
}
