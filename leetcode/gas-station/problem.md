## 题目描述

在一条环路上有 `n` 个加油站，第 `i` 个加油站有汽油 `gas[i]` 升。

你有一辆油箱容量无限的汽车，从第 `i` 个加油站开往第 `i + 1` 个加油站需要消耗汽油 `cost[i]` 升。你从其中一个加油站出发，开始时油箱为空。

如果你可以绕环路行驶一周，返回出发时加油站的编号，否则返回 `-1`。

本题对应 LeetCode 134. Gas Station（文档第 85 题第一问）。

## 输入格式

第一行一个整数 `n`，表示加油站个数。
第二行 `n` 个整数 `gas[0..n-1]`。
第三行 `n` 个整数 `cost[0..n-1]`。
相邻数字均用空格分隔。

## 输出格式

输出一个整数：能绕环路一周的出发加油站编号（下标从 0 开始）；无解输出 `-1`。

题目保证有解时答案唯一。

## 示例

### 示例 1

输入：
```
5
1 2 3 4 5
3 4 5 1 2
```

输出：
```
3
```

解释：从 3 号站出发，油箱变化是 4-1=3、5-2=3、1-3=-2、2-4=-2、3-5=-2，全程油量从不为负，正好回到 3 号站。

### 示例 2

输入：
```
3
2 3 4
3 4 3
```

输出：
```
-1
```

解释：总油量 9 升、总消耗 10 升，怎么走都不够，无解。

### 示例 3

输入：
```
1
5
4
```

输出：
```
0
```

解释：只有一个加油站，5 - 4 = 1 升足够开回自己，从 0 号站出发即可。

## 数据范围

- `1 <= n <= 10^5`
- `0 <= gas[i], cost[i] <= 10^4`
- 进阶：时间 O(n)、空间 O(1)
