## 题目描述

给定一棵二叉树的**层序遍历序列**（空节点用 `#` 表示），返回二叉树**每一层的节点个数**，从根所在层（第 1 层）开始按层号从小到大输出。

请分别用**递归**（DFS，传递层号）和**非递归**（BFS 队列）两种思路实现，并说清各自的时间复杂度与空间复杂度。

> 本题是原文档第 52 题，没有对应的 LeetCode 题号，属于经典面试题。

## 输入格式

一行，二叉树的层序序列，节点值之间用空格分隔，空节点用 `#` 表示。

空节点的孩子不再列出（与 LeetCode 的数组表示一致）。例如 `3 9 20 # # 15 7` 表示：根是 3，左孩子 9、右孩子 20；9 的左右孩子都为空，所以紧接着的两个 `#` 是 9 的孩子；20 的左孩子是 15、右孩子是 7。

若输入为空行或第一个节点就是 `#`，表示空树。

## 输出格式

输出一行，第 1 层到最后一层的节点数，相邻数字用空格分隔。
若为空树，输出 `0`（输出一个 0 而不是空行，方便对拍）。

## 示例

### 示例 1

输入：
```
3 9 20 # # 15 7
```

输出：
```
1 2 2
```

解释：第 1 层只有根 3；第 2 层是 9、20；第 3 层是 20 的孩子 15、7。

### 示例 2

输入：
```
1 2 3 4
```

输出：
```
1 2 1
```

解释：根 1；第 2 层是 2、3；`4` 是 2 的左孩子，所以第 3 层只有 1 个节点（序列到此结束，3 的左右孩子都按空处理）。

### 示例 3

输入：
```
1 2 # 3
```

输出：
```
1 1 1
```

解释：根 1；它的左孩子是 2、右孩子为空；2 的左孩子是 3。整棵树退化成一条链，每层各 1 个节点。

### 示例 4

输入：
```
# 
```

输出：
```
0
```

解释：空树，约定输出 `0`。

## 数据范围

- 节点总数 `0 <= n <= 10^4`（`n = 0` 表示空树，输入为空行）
- 节点值为 32 位整数（可能为负、可能重复）
- 层序序列的长度不超过 `2 * 10^4`
