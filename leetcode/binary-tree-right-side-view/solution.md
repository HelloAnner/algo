## 思路

**按层遍历（BFS）**：右视图的每一层只取一个节点，就是这个**层的最右节点**。

- 第一遍：把层序序列还原成二叉树。用一个队列保存「已经建好、还没分配孩子的节点」，同时用一个指针 `idx` 指向序列中下一个待分配的孩子 token：每次从队首取出一个节点，把 `tok[idx]` 作为它的左孩子、`tok[idx + 1]` 作为它的右孩子，`idx += 2`；孩子非空时才入队、才参与后续分配。
- 第二遍：从根开始做 BFS，一次处理一整层（先记下当前队列大小 `sz`），这一层里第 `sz` 个（最后一个）节点的值就是右视图里的一个答案。

**为什么对**：站在右侧时，同一层里只有最右边的节点不会被同一层的其他节点挡住（下层节点只会挡住它上方节点右边的视野，而同一层最右节点上方的那列才是可见的），因此右视图 = 每层最右节点、自上而下。

也可以不用 BFS：按「根 → 右 → 左」做 DFS，每个深度**第一次**访问到的节点必定是该层最右节点，同样能收集答案（文档里没有给解法，两种都可以）。

## 复杂度

- 时间：O(n)，建树与层序遍历各扫一遍
- 空间：O(n)，存树与队列

## 关键点

- LeetCode 的层序序列里，`null` 节点的孩子**不会出现**，所以要用「队列 + 双 token 分配」的方式建树，不能直接按下标 `2i+1 / 2i+2` 取孩子
- 记录每层最后一个节点时，要在出队前用 `sz = q.size()` 固定本层节点数，否则会把下一层混进来
- 空树要输出空行，不要输出任何数字
- 输入含 `null` 这种非数字 token，读进来用 `string` 再判断 / 转换
- 节点值可能为负，判断「空」不能用 `-1` 之类的哨兵值去替代 `null`
