题目：二叉树的层序遍历
链接：https://leetcode.cn/problems/binary-tree-level-order-traversal/
难度：中等

[题目描述]
给你一棵二叉树，返回其按层序遍历得到的节点值，即逐层地、从左到右访问所有节点，每一层的值作为独立的一行输出。

[输入格式]
第一行一个整数 n，表示层序数组的长度。
第二行 n 个整数，为二叉树的层序（BFS）序列，其中 -1 表示空节点（null）。

序列的构造方式与 LeetCode 相同：按下标 i 从 0 开始依次填节点，下标 i 的左右孩子分别是 2i+1 和 2i+2；某个位置是 -1 就表示该位置没有节点（它的孩子也不会出现在数组里）。数组末尾连续的 -1 可以省略。

因为用 -1 表示空节点，所以本题保证节点值都是非负整数。

[输出格式]
每一层输出一行，为该层从左到右的节点值，相邻数字用空格分隔。
树保证非空，至少输出一行。

[示例 1]
输入：
7
3 9 20 -1 -1 15 7
输出：
3
9 20
15 7
解释：根是 3；第二层从左到右是 9、20；第三层是 15、7。

树形如下：

        3
       / \
      9   20
         /  \
        15   7

[示例 2]
输入：
1
1
输出：
1
解释：只有一个根节点，输出一行。

      1

[示例 3]
输入：
7
1 2 3 4 -1 -1 5
输出：
1
2 3
4 5
解释：4 是 2 的左孩子，5 是 3 的右孩子（中间的空位用 -1 占位），第三层从左到右是 4、5。

树形如下：

        1
       / \
      2   3
     /     \
    4       5

[数据范围]
- 1 <= 节点个数 <= 2000
- 1 <= n <= 4000（层序数组长度，含 -1 占位）
- 0 <= 节点值 <= 1000（因此可以用 -1 表示空节点）
- 树的深度不超过 1000，允许退化成一条链的极端形状
