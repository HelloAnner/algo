题目：最小栈
链接：https://leetcode.cn/problems/min-stack/
难度：中等

[题目描述]
设计一个支持 push、pop、top 操作，并能在常数时间内检索到最小元素的栈。

实现 MinStack 类：

- push(x) —— 将元素 x 推入栈中。
- pop() —— 删除栈顶的元素。
- top() —— 获取栈顶元素。
- getMin() —— 检索栈中的最小元素。

双栈示意（依次 push -2、push 0、push -3 之后）：

   data 栈               minStack 栈
   +------+              +------+
   |  -3  | <- 栈顶      |  -3  | <- 栈顶：当前最小值
   +------+              +------+
   |   0  |              |  -2  |
   +------+              +------+
   |  -2  |              +------+
   +------+

   弹出 -3 时两个栈一起弹，minStack 的新栈顶 -2 就是剩下元素的最小值；
   压入比当前最小值大的数时 minStack 不动，弹出它时 minStack 也不动。

[输入格式]
第一行一个整数 q，表示操作条数。

接下来 q 行，每行是一条操作：

- push x —— 把整数 x 压入栈中；
- pop —— 弹出栈顶元素；
- top —— 查询栈顶元素；
- getMin —— 查询当前栈中的最小元素。

[输出格式]
按输入顺序，对每个 top 和 getMin 操作各输出一行结果。push 和 pop 不产生输出。

[示例 1]
输入：
7
push -2
push 0
push -3
getMin
pop
top
getMin
输出：
-3
0
-2
解释：依次压入 -2、0、-3 后最小值为 -3；弹出 -3 之后栈顶是 0，此时栈中最小值是 -2。

[示例 2]
输入：
9
push 1
push 1
getMin
pop
getMin
top
pop
push 5
getMin
输出：
1
1
1
5
解释：压入两个 1 时辅助栈也必须压入两次，否则弹出一个 1 之后最小值就丢了——这是本题最容易写错的地方。最后一次只剩 5，最小值是 5。

[示例 3]
输入：
4
push 2147483647
push -2147483648
getMin
top
输出：
-2147483648
-2147483648
解释：元素可能取到 INT_MIN，不要把 0 或 -1 当成「空」的哨兵值。

[数据范围]
- -2^31 <= x <= 2^31 - 1
- 1 <= q <= 3 * 10^4
- pop、top、getMin 只会在栈非空时被调用
- 要求 push / pop / top / getMin 的时间复杂度均为 O(1)

[备注]
原文档这一节的标题是「最大栈」，但 LeetCode 716 最大栈是会员专享题，文档实际给出的是同型的「最小栈」（示例里调用的就是 getMin），因此这里按最小栈实现，思路与最大栈完全对称。
