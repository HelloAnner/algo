题目：完全二叉树的节点个数
链接：https://leetcode.cn/problems/count-complete-tree-nodes/
难度：中等

[题目描述]

给定一棵完全二叉树，求它的节点个数。要求算法优于 O(n)（不能老老实实遍历每个节点），并分析复杂度。

完全二叉树的定义：除最后一层外，每一层都是满的；最后一层的节点全部靠左排列。

本题对应 LeetCode 222. Count Complete Tree Nodes，是 ACM 模式：输入是这棵树的先序序列，输出节点个数。

[输入格式]

一行若干 token，按先序（根 → 左 → 右）给出这棵树：整数表示一个节点，# 表示空节点。读到文件结束（EOF）为止。

题目保证给出的树是完全二叉树。

[输出格式]

输出一个整数，表示节点个数。空树输出 0。

[示例 1]

输入：
1 2 4 # # 5 # # 3 6 # # #

输出：
6

解释：先序序列还原出来的树是

            1
          /   \
         2     3
        / \   /
       4   5 6

层序看这棵树是 [1, 2, 3, 4, 5, 6]：1 的左 2 右 3，2 的左 4 右 5，3 的左 6，是完全二叉树，共 6 个节点。

先序序列与空节点的对应：

    1  2  4  #  #  5  #  #  3  6  #  #  #
    |  |  |        |        |  |
    |  |  |        |        |  +-- 6 的左右孩子都是空
    |  |  |        |        +----- 3 只有左孩子 6，右孩子为空
    |  |  |        +-------------- 2 的左 4、右 5
    |  |  +----------------------- 2 的左孩子是 4
    |  +-------------------------- 1 的左孩子是 2
    +----------------------------- 1 的右孩子是 3

[示例 2]

输入：
1 # #

输出：
1

解释：只有一个根节点，左右孩子都是空：

      1
     / \
    #   #

[示例 3]

输入：
#

输出：
0

解释：空树，节点个数为 0。

[数据范围]

- 0 <= 节点个数 <= 10^5
- -1000 <= 节点值 <= 1000
- 要求时间复杂度优于 O(n)，即 O(log^2 n)（也有 O(log n) 的位运算做法）
