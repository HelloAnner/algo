## 思路

利用完全二叉树的性质：

- 从某个节点出发，沿**最左路径**一直走到底，得到的节点数记为它所在满二叉树的高度。
- 对根节点分别求左子树的最左深度 `ld` 和右子树的最左深度 `rd`：
  - `ld == rd`：说明左子树是一棵高度为 `ld` 的**满二叉树**，节点数是 `2^ld - 1`，加上根节点就是 `2^ld` 个，剩下只需递归数右子树；
  - `ld != rd`：说明右子树是一棵高度为 `rd` 的满二叉树，节点数是 `2^rd - 1`，加上根节点就是 `2^rd` 个，剩下只需递归数左子树。

每递归一层都能「白拿」一整棵子树，而求最左深度只要 O(log n)，递归深度也只有 O(log n)，所以总复杂度是 `O(log^2 n)`。

> 说明：本题的 ACM 输入是序列化后的树，所以直接数一数非 `#` 的 token 也能得到答案；但面试考的正是上面这个「不遍历所有节点」的做法，`solution.cpp` 实现的就是它。

## 复杂度

- 时间：`O(log^2 n)`，每层用 O(log n) 求最左深度，一共 O(log n) 层
- 空间：`O(log n)` 递归栈（建树本身要 O(n)）

## 关键点

- 判满的条件是「左子树最左深度 == 右子树最左深度」，不是比较两棵子树的高度
- 完全二叉树里空节点只会出现在最后，不会出现「左边缺、右边有」
- `(1 << ld)` 在节点数 `<= 10^5` 时不会溢出（`ld <= 17`）
- 边界：空树返回 0；单节点树返回 1
