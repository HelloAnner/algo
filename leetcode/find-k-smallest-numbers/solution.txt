[思路]

维护一个大小为 k 的大顶堆（C++ 里就是默认的 priority_queue<int>，堆顶是最大值）：

1. 按顺序读入每个数 x：
   - 堆里不足 k 个：直接 push(x)；
   - 堆里已有 k 个且 x < 堆顶：弹出堆顶再 push(x)（堆顶是候选集合里最大的，也就是当前的「第 k 小」，比它大的数不可能入选）；
   - 否则 x 不可能是最小的 k 个之一，直接丢弃。
2. 全部读完后，堆里剩下的恰好就是最小的 k 个数。
3. 依次弹出堆顶（这时是从大到小），逆序即为升序答案。

             7            <- 堆顶 = 候选里最大 = 当前第 k 小
           /   \
          3     5              x < 7  ->  弹出 7，push x
         /                     x >= 7 ->  丢弃 x
        1

以示例 1 为例（a = 1 3 5 7 2 4 6 8，k = 4）：

    push 1        候选 {1}           堆顶 1
    push 3        候选 {1,3}         堆顶 3
    push 5        候选 {1,3,5}       堆顶 5
    push 7        候选 {1,3,5,7}     堆顶 7（当前第 4 小）
    x = 2 < 7     弹出 7，push 2      候选 {1,2,3,5}     堆顶 5
    x = 4 < 5     弹出 5，push 4      候选 {1,2,3,4}     堆顶 4
    x = 6 >= 4    丢弃
    x = 8 >= 4    丢弃

    依次弹出堆顶：4 3 2 1，逆序 -> 1 2 3 4

因为全程只保留 k 个候选，空间是 O(k)，时间 O(n log k)——正是文档里「10 亿个数取最小 100 个」可行的做法：不需要把数据一次读进内存，流式处理即可。

[复杂度]
时间：O(n log k)（每个元素最多一次 push + 一次 pop，堆大小不超过 k）   空间：O(k)（堆 + 输出数组）

[关键点]

- 求最小的 k 个要用大顶堆（堆顶最大、最容易淘汰）；求最大的 k 个才用小顶堆，方向别搞反
- 判断条件写 x < pq.top()：等于堆顶时换不换都对答案没影响，用严格小于更省操作
- 大顶堆的弹出顺序是从大到小，输出前记得 reverse（或者弹出时头插）
- a[i] 最大 10^9，单个元素用 int 足够（本题只做比较，不做求和）
- k == n 时堆里就是全部元素，等价于一次完整排序，结果依然正确
- 对比取舍：也可以全部读入后 sort 取前 k 个（O(n log n) 时间、O(n) 空间），或者用 nth_element（期望 O(n)），但都不满足「数据大到放不进内存」的前提

[C++ 代码]
// 找 K 个最小值
// 面试经典题（非 LeetCode 原题；同类：LeetCode 面试题 17.14 最小 K 个数）
//
// 思路：用大小为 k 的大顶堆在线维护候选集合，堆顶是当前第 k 小，比它大的数直接丢弃。
// 复杂度：时间 O(n log k) 空间 O(k)
#include <algorithm>
#include <iostream>
#include <queue>
#include <vector>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n = 0, k = 0;
    if (!(cin >> n >> k)) return 0;

    priority_queue<int> heap;  // 大顶堆：堆顶是候选集合中最大的数
    for (int i = 0; i < n; ++i) {
        int x = 0;
        cin >> x;
        if (static_cast<int>(heap.size()) < k) {
            heap.push(x);
        } else if (x < heap.top()) {
            heap.pop();
            heap.push(x);
        }
    }

    vector<int> ans;
    ans.reserve(heap.size());
    while (!heap.empty()) {
        ans.push_back(heap.top());
        heap.pop();
    }
    reverse(ans.begin(), ans.end());  // 大顶堆弹出是从大到小，逆序变升序

    for (size_t i = 0; i < ans.size(); ++i) {
        if (i > 0) cout << ' ';
        cout << ans[i];
    }
    cout << '\n';
    return 0;
}
