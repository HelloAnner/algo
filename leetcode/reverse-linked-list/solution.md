## 思路

题目来自文档中的 Java 解法，这里翻译成 C++ 的两种写法。

**写法一：递归**

`reverseList(head)` 的定义是「反转以 head 为头的链表，返回新的头」：

1. 边界：`head == nullptr || head->next == nullptr` 时直接返回 `head`（空链表或单节点无需反转）；
2. 否则先递归反转 `head->next`，得到反转后的新头 `cur`；
3. 此时 `head->next` 是后半段反转后的**尾节点**，让 `head->next->next = head`、`head->next = nullptr`，就把 `head` 接到了尾部；
4. 返回 `cur`。

正确性来自归纳：假设递归调用已经把「除 head 外的 n-1 个节点」正确反转并返回新头，那么把 head 挂到它的尾部，就得到整条链的反转。

**写法二：迭代（本题 `solution.cpp` 采用，也是面试首选）**

三个指针：

- `pre`：已反转部分的头（初始 `nullptr`）；
- `cur`：尚未处理部分的头（初始 `head`）；
- 循环里先用 `nxt` 暂存 `cur->next`（否则改指针后后半段就丢了），然后 `cur->next = pre`、`pre = cur`、`cur = nxt`。

不变量：`[head, cur)` 这一段已经全部反转且 `pre` 指向它的头。每轮把 `cur` 摘下来头插到 `pre` 前面，不变量保持。`cur` 走到 `nullptr` 时整条链反转完毕，`pre` 就是新头。

本题只需要输出反转后的序列，但 `solution.cpp` 里依然**真的建了链表并改指针**——这正是这道题要练的手写链表能力。节点内存用 `std::unique_ptr` 池统一持有，不会泄漏。

## 复杂度

- 时间：O(n)，每个节点恰好被访问（并改一次指针）一次
- 空间：迭代 O(1)；递归 O(n)（递归栈深度），文档里的递归写法同理

## 关键点

- 迭代时**必须先保存 `cur->next`**，再改 `cur->next`，顺序反了就断链
- 循环结束时返回的是 `pre` 而不是 `cur`（`cur` 已经是 `nullptr`）
- 空链表 `n = 0` 要单独处理，别去解引用空指针
- 递归写法在 n = 5000 时递归深度 5000，一般不会爆栈，但工程上更推荐迭代
- 本题只要求输出值，所以「不改变节点值、只改指针」这个要求在这里体现为：`solution.cpp` 确实做了指针操作，而不是把数组 `reverse` 一下
