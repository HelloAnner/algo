## 题目描述

给你单链表的头节点 `head`，请你反转链表，并返回反转后的链表。

本题是 ACM 模式：读入链表的节点值，把链表真正反转后按顺序输出。

## 输入格式

第一行一个整数 `n`，表示链表的节点个数。
第二行 `n` 个整数，依次表示链表从头到尾每个节点的值，相邻数字用空格分隔。

若 `n = 0`，则没有第二行（空链表）。

## 输出格式

输出一行，包含反转后的链表从头到尾每个节点的值，相邻数字用空格分隔。
若 `n = 0`，输出一个空行。

## 示例

### 示例 1

输入：
```
5
1 2 3 4 5
```

输出：
```
5 4 3 2 1
```

解释：原链表为 1->2->3->4->5->NULL，反转后为 5->4->3->2->1->NULL。

### 示例 2

输入：
```
2
1 2
```

输出：
```
2 1
```

解释：只有两个节点，把 `head->next` 指向 `head` 即可，结果是 2->1。

### 示例 3

输入：
```
1
7
```

输出：
```
7
```

解释：只有一个节点，反转后仍是它自己（递归解法的边界条件也在这里）。

## 数据范围

- `0 <= n <= 5000`
- `-5000 <= Node.val <= 5000`
- 进阶：分别用**迭代**和**递归**两种方法实现；递归版本的空间复杂度是 O(n)。
