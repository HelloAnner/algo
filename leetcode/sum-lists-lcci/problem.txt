题目：链表求和
链接：https://leetcode.cn/problems/sum-lists-lcci/
难度：中等

[题目描述]
给定两个用链表表示的整数，每个节点包含一个数位。这些数位是「反向存放」的，也就是个位排在链表首部。

编写函数对这两个整数求和，并用链表形式返回结果（结果链表同样是个位排在首部）。

    617 用链表表示： 7 -> 1 -> 6 -> null      （个位在首部，正好是从低位到高位）
    295 用链表表示： 5 -> 9 -> 2 -> null

        7 -> 1 -> 6 -> null          617
      + 5 -> 9 -> 2 -> null        + 295
        -------------------        -----
        2 -> 1 -> 9 -> null          912

    逐位相加（carry 是进位，从低位往高位走）：

        数位:    7    1    6
               + 5    9    2
               ---------------
                 2    1    9
        进位:    1    1    0

    7 + 5 = 12，写 2 进 1；1 + 9 + 1 = 11，写 1 进 1；6 + 2 + 1 = 9，不进位。

    示例 2：最高位还要再进一位

        5 -> null
        9 -> 9 -> 9 -> null          5 + 999 = 1004
        -------------------
        4 -> 0 -> 0 -> 1 -> null     ← 循环条件里必须带上 carry，否则会丢掉最高位

进阶：假设这些数位是「正向存放」的（个位在链表末尾），请再做一遍。

[输入格式]
共四行：

1. 第一行一个整数 n，表示第一个链表的长度；
2. 第二行 n 个整数 a[0..n-1]，个位在前（a[0] 是个位），相邻数字用空格分隔；
3. 第三行一个整数 m，表示第二个链表的长度；
4. 第四行 m 个整数 b[0..m-1]，同样个位在前，空格分隔。

[输出格式]
一行，从个位到最高位依次输出求和结果链表的每个数位，相邻数字用空格分隔。

[示例 1]
输入：
3
7 1 6
3
5 9 2
输出：
2 1 9
解释：7 -> 1 -> 6 表示 617，5 -> 9 -> 2 表示 295，617 + 295 = 912，反向存放即 2 -> 1 -> 9。

[示例 2]
输入：
1
5
3
9 9 9
输出：
4 0 0 1
解释：5 + 999 = 1004，个位在前输出 4 0 0 1；注意最高位新产生的进位要额外补一个节点。

[数据范围]
- 1 <= n, m <= 100
- 0 <= 每个数位 <= 9
- 两个链表表示的都是非负整数，且没有前导零（整数 0 用单节点 0 表示）
- 结果可能超出 32 位整数范围，必须逐位模拟加法，不能转成整数再相加
