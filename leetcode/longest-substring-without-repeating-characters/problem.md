## 题目描述

请从字符串 `s` 中找出一个**最长的不包含重复字符的子字符串**，计算该最长子字符串的长度。

子串必须是连续的字符序列（`pwke` 是子序列，不是子串，不能算）。

## 输入格式

一行，一个字符串 `s`（只含 ASCII 可见字符，不含空格；空行表示空串）。

## 输出格式

输出一个整数，表示最长不含重复字符的子串长度。

## 示例

### 示例 1

输入：
```
abcabcbb
```

输出：
```
3
```

解释：最长的不含重复字符的子串是 `abc`，长度为 3。

### 示例 2

输入：
```
bbbbb
```

输出：
```
1
```

解释：最长的不含重复字符的子串是 `b`，长度为 1。

### 示例 3

输入：
```
pwwkew
```

输出：
```
3
```

解释：最长的不含重复字符的子串是 `wke`，长度为 3。注意 `pwke` 是子序列，不算。

## 数据范围

- `0 <= s.length <= 40000`
- `s` 由 ASCII 可见字符组成（不含空格、制表符和换行）
