题目：合并排序的数组
链接：https://leetcode.cn/problems/sorted-merge-lcci/
难度：简单

[题目描述]
给定两个排序后的数组 A 和 B，其中 A 的末端有足够的缓冲空间容纳 B。编写一个方法，将 B 合并入 A 并排序。

初始化时 A 和 B 的元素数量分别为 m 和 n（A 的总长度为 m + n，最后 n 个位置是缓冲空位）。

本题用 stdin/stdout 判题：读入两个数组的有效部分，输出合并后的完整有序数组。

    A 的有效部分        缓冲空位
    +----+----+----+----+----+----+
    |  1 |  2 |  3 |    |    |    |      m = 3，A 的总长是 6
    +----+----+----+----+----+----+

    B
    +----+----+----+
    |  2 |  5 |  6 |                      n = 3
    +----+----+----+

[输入格式]
第一行两个整数 m 和 n，用空格分隔。
第二行 m 个整数，表示 A 的有效元素（非递减有序）；m = 0 时该行为空行。
第三行 n 个整数，表示 B 的全部元素（非递减有序）；n = 0 时该行为空行。

（空行只是写法上的示意，用 cin >> 读入时空白符会被自动跳过。）

[输出格式]
一行 m + n 个整数，表示合并后的非递减数组，相邻数字用空格分隔。
若 m + n == 0，输出一个空行。

[示例 1]
输入：
3 3
1 2 3
2 5 6
输出：
1 2 2 3 5 6
解释：A = [1,2,3]，B = [2,5,6]，合并后为 [1,2,2,3,5,6]。

    双指针从后往前归并：i 指向 A 的有效末尾，j 指向 B 的末尾，k 指向 A 的写入位置。

      A:  1  2  3  _  _  _          B:  2  5  6
                    ^                        ^
                    i                        j
                    k（写入位置）

    每步比较 A[i] 与 B[j]，把较大者写到 A[k]，然后指针一起前移：

      写 B[2]=6：  A = 1 2 3 _ _ 6     i=2  j=1  k=4
      写 B[1]=5：  A = 1 2 3 _ 5 6     i=2  j=0  k=3
      写 A[2]=3：  A = 1 2 3 3 5 6     i=1  j=0  k=2
      写 B[0]=2：  A = 1 2 2 3 5 6     i=1  j=-1 k=1（B 用完）
      搬 A 剩下的： A = 1 2 2 3 5 6     i=-1 k=-1

[示例 2]
输入：
3 0
1 2 3
输出：
1 2 3
解释：B 为空（n = 0），结果就是 A 本身。

[示例 3]
输入：
0 3
-3 0 7
输出：
-3 0 7
解释：A 为空（A 的长度就是 3，全是缓冲位），结果就是 B。

[数据范围]
- 0 <= m, n，且 A.length == m + n
- A、B 均为非递减有序数组
- 元素为 32 位有符号整数
