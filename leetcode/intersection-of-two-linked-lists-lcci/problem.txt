题目：链表相交
链接：https://leetcode.cn/problems/intersection-of-two-linked-lists-lcci/
难度：简单

[题目描述]

给定两个单向链表 A、B，判断它们是否相交，并返回相交的起始节点。

这里的「相交」是引用意义上的相交，与节点的值无关：如果链表 A 的第 k 个节点与链表 B 的第 j 个节点是同一个节点（内存中的同一块地址），则两个链表相交。题目保证链表中没有环，且链表结构在返回结果后仍须保持原样。

相交的示意图（两条链表共享尾部节点，C 为相交节点）：

    A:  a0 -> a1 -> ... -> a[skipA-1] -> C -> c1 -> c2 -> ...
                                        ^
                                        |
    B:  b0 -> b1 -> ... -> b[skipB-1] --+

    从 C 开始，两条链表用的是同一批节点对象（同一块内存地址）。
    示例 1 里 C 就是值为 8 的那个节点：

    A:  4 -> 1 -> 8 -> 4 -> 5
                  ^
                  |
    B:  5 -> 0 -> 1

不相交的示意图（skipA = skipB = -1）：

    A:  2 -> 6 -> 4 -> NULL
    B:  1 -> 5 -> NULL

[输入格式]

第一行两个整数 n、m，分别表示链表 A、B 的节点个数。

第二行 n 个整数 a[0..n-1]，为链表 A 从表头到表尾的节点值。

第三行 m 个整数 b[0..m-1]，为链表 B 从表头到表尾的节点值。

第四行两个整数 skipA、skipB：

- 若两个链表相交：从 A 的表头到相交节点之间有 skipA 个节点，从 B 的表头到相交节点之间有 skipB 个节点（相交节点本身属于公共部分）；
- 若两个链表不相交：skipA = skipB = -1。

评测程序会按 skipA、skipB 把两条链表真正接成共享尾部节点的结构，因此相交与否是按节点引用判定的。数据保证 b[skipB + i] == a[skipA + i]。

[输出格式]

输出一行一个整数：相交节点的值；若两个链表不相交，输出 -1。

[示例 1]
输入：
5 6
4 1 8 4 5
5 0 1 8 4 5
2 3
输出：
8
解释：A = [4,1,8,4,5]，B = [5,0,1,8,4,5]。从 A 的表头走 2 步、从 B 的表头走 3 步后到达同一个节点（值为 8），因此返回 8。

[示例 2]
输入：
5 3
0 9 1 2 4
3 2 4
3 1
输出：
2
解释：A 的独有部分是 [0,9,1]，B 的独有部分是 [3]，之后两条链表共享节点 [2,4]，相交节点的值为 2。

[示例 3]
输入：
3 2
2 6 4
1 5
-1 -1
输出：
-1
解释：两条链表没有公共节点，返回 -1。

[数据范围]

- 1 <= n, m <= 10^5
- 0 <= 节点值 <= 10^4
- 相交时 0 <= skipA < n、0 <= skipB < m；不相交时 skipA = skipB = -1
- 链表无环
- 要求时间 O(n + m)、额外空间 O(1)
