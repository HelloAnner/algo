## 题目描述

`n` 个朋友围成一圈，编号为 `1` 到 `n`。从 1 号开始报数，每次数到 `m` 的人出圈，然后从下一个人继续从 1 开始报数，直到只剩下一个人。求最后剩下的那个人的编号。

这就是约瑟夫环问题。本题对应 LeetCode 1823. Find the Winner of the Circular Game；剑指 Offer 62. 圆圈中最后剩下的数字是同一个问题的 `0` 起始编号版本（它的答案等于本题答案减 1）。文档第 87 题给的例子 `n = 5, m = 3, 答案 3` 用的是从 0 编号的口径。

## 输入格式

一行两个整数 `n` 和 `m`，分别表示人数和每次报数的数。

## 输出格式

输出一个整数，表示最后剩下的那个人的编号（`1 ~ n`）。

## 示例

### 示例 1

输入：
```
5 2
```

输出：
```
3
```

解释：出圈顺序是 2、4、1、5，最后剩下 3 号。

### 示例 2

输入：
```
6 5
```

输出：
```
1
```

解释：出圈顺序是 5、4、6、2、3，最后剩下 1 号。

### 示例 3

输入：
```
5 3
```

输出：
```
4
```

解释：从 1 编号看，出圈顺序是 3、1、5、2，最后剩下 4 号（对应剑指 Offer 62 的答案 3）。

## 数据范围

- `1 <= n <= 10^5`
- `1 <= m <= 10^6`
- 进阶：时间 O(n)、空间 O(1)，不要用链表真的模拟出圈过程（那是 O(n * m)）
