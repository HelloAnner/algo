[思路]

位图 + 下标平移（2 bit 计数），对应文档里 Java 版的位图思路：

1. 先扫一遍数据求出最小值 min 和最大值 max。42 亿的取值范围直接开位图太大，把下标整体平移 min 之后，位图只需要覆盖 [min, max] 这一段。
2. 开一个位图，每个数字占 2 bit，记录它出现过的次数（0 / 1 / 2 / 3，计数到 3 就饱和，3 表示出现 3 次及以上）。
   - 下标 i = a[k] - min；
   - 所在字节 byte = i >> 2，字节内偏移 shift = (i & 3) * 2；
   - 计数 cnt = (bitmap[byte] >> shift) & 3：只要 cnt < 3 就加一（0 -> 1 -> 2 -> 3），加到 3 之后保持不变。
3. 位图的下标天然有序，从头到尾扫一遍，凡是计数等于 2 的位置，其对应数字就是 min + i，直接按升序输出。
4. 一个都没有时输出 -1。

一个字节装 4 个「2 bit 计数器」（画的是同一个字节里的位）：

     bit7  bit6     bit5  bit4     bit3  bit2     bit1  bit0
    +-----------+-----------+-----------+-----------+
    |  cnt[i]   | cnt[i+1]  | cnt[i+2]  | cnt[i+3]  |
    +-----------+-----------+-----------+-----------+
          ^
          shift = (i & 3) * 2，取数用 (bitmap[byte] >> shift) & 3

以示例 1 为例（a = 1 2 3 2 4 5 3，min = 1，max = 5，位图覆盖 [1, 5]）：

    a[k]     1    2    3    2    4    5    3
    下标 i   0    1    2    1    3    4    2      (i = a[k] - min)
    计数     1    1    1    2    1    1    2
                   ^                        ^
              第一次到 2               第二次到 2

    扫位图：i = 1 -> 数字 2（计数 2），i = 2 -> 数字 3（计数 2）
    输出：2、3（升序）

如果像文档的 Java 代码那样每个数字只用 1 bit（只记「出现过没有」），第二次遇到时打印即可，但那样无法区分「出现 2 次」和「出现更多次」；本题用 2 bit 更严谨，也能顺便省掉一次排序。

[复杂度]
时间：O(n + (max - min))（一遍读入统计、一遍扫位图输出）   空间：O((max - min) / 4) 字节，即每个数字 2 bit（本题规模约 5 MB）

[关键点]

- 数值范围到 42 亿，超过 int（约 21.47 亿），必须用 long long；位图下标要用 64 位算完再转 size_t
- 下标一定要平移 min，否则位图长度按 max 开，既慢又费内存（文档 Java 代码里的 num / 8 - min / 8 就是在做平移）
- 2 bit 计数要用掩码取：(bitmap[byte] >> shift) & 3，不能写成只适合 1 bit 的 (bitmap[byte] & (1 << k)) > 0
- 按位图顺序输出天然升序，不需要再 sort；若改用哈希表统计就得额外排序
- 空结果输出 -1，注意别输出空行
- 其他解法：排序后扫一遍（O(n log n)、除输入外空间 O(1)），或哈希表/哈希集合（O(n) 时间但空间远大于位图）

[C++ 代码]
// 找出重复元素
// 面试经典题：n 个 0~42 亿的正整数，找出所有恰好出现 2 次的数字
//
// 思路：先求 min/max 把位图下标平移，每个数字用 2 bit 计数（到 3 饱和），再顺序扫描位图输出恰好 2 次的数字。
// 复杂度：时间 O(n + max-min) 空间 O((max-min)/4) 字节
#include <algorithm>
#include <iostream>
#include <vector>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n = 0;
    if (!(cin >> n)) return 0;

    vector<long long> a(n);
    long long lo = 0, hi = 0;
    for (int i = 0; i < n; ++i) {
        cin >> a[i];
        if (i == 0) {
            lo = hi = a[i];
        } else {
            lo = min(lo, a[i]);
            hi = max(hi, a[i]);
        }
    }

    // 位图下标平移 lo，只覆盖 [lo, hi]；每个数字 2 bit 记录出现次数（0/1/2，到 3 饱和）
    unsigned long long span = static_cast<unsigned long long>(hi - lo) + 1ULL;
    vector<unsigned char> bitmap(static_cast<size_t>((span + 3ULL) / 4ULL), 0);

    for (long long v : a) {
        size_t idx = static_cast<size_t>(v - lo);
        size_t byte = idx >> 2;
        int shift = static_cast<int>(idx & 3ULL) * 2;
        int cnt = (bitmap[byte] >> shift) & 3;
        if (cnt < 3) {
            // 0->1、1->2、2->3（3 表示出现 3 次及以上，不再是「恰好 2 次」）
            bitmap[byte] = static_cast<unsigned char>(bitmap[byte] + (1 << shift));
        }
    }

    bool any = false;
    for (unsigned long long i = 0; i < span; ++i) {
        size_t byte = static_cast<size_t>(i >> 2);
        int shift = static_cast<int>(i & 3ULL) * 2;
        if (((bitmap[byte] >> shift) & 3) == 2) {
            cout << (lo + static_cast<long long>(i)) << '\n';
            any = true;
        }
    }
    if (!any) cout << -1 << '\n';
    return 0;
}
