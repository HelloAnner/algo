## 题目描述

给定一个二叉树，返回它的**前序**遍历（根 → 左 → 右）得到的节点值序列。

**进阶**：递归算法很简单，你可以通过**迭代**算法完成吗？（本目录的实现用显式栈迭代完成，不使用递归。）

## 输入格式

- 第一行一个整数 `n`，表示层序数组（含 `null` 占位）的元素个数，`n = 0` 表示空树；
- 第二行 `n` 个 token，空格分隔，每个 token 是一个整数或 `null`，按层序（LeetCode 习惯）描述一棵二叉树（`n = 0` 时该行可以省略）。

## 输出格式

一行，前序遍历得到的节点值序列，相邻数字用空格分隔；空树输出一个空行。

## 示例

### 示例 1

输入：
```
4
1 null 2 3
```

输出：
```
1 2 3
```

解释：树为根 `1`、右孩子 `2`、`2` 的左孩子 `3`，前序为 `1 -> 2 -> 3`（左子树为空）。

### 示例 2

输入：
```
7
1 2 3 4 5 6 7
```

输出：
```
1 2 4 5 3 6 7
```

解释：完全二叉树前序先一路向左输出 `1 2 4`，再输出左子树的右孩子 `5`，然后才是右子树 `3 6 7`。

## 数据范围

- 树中节点数目范围 `[0, 100]`
- `-100 <= Node.val <= 100`
