## 思路

前序 = 根 → 左 → 右。递归写法就是「先访问根，再递归左子树，再递归右子树」，但递归的调用栈是隐式的；迭代版本用**显式栈**模拟这个过程。

关键技巧：栈是后进先出，所以**先压右孩子、再压左孩子**，这样出栈时左孩子先被访问：

```cpp
vector<int> res;
vector<TreeNode*> stk;
if (root != nullptr) stk.push_back(root);
while (!stk.empty()) {
    TreeNode* p = stk.back(); stk.pop_back();
    res.push_back(p->val);                  // 访问根
    if (p->right) stk.push_back(p->right);  // 右孩子先入栈（后访问）
    if (p->left)  stk.push_back(p->left);   // 左孩子后入栈（先访问）
}
```

**为什么对？** 每个节点恰好出栈一次并在此刻被输出。对任意节点 `p`：当 `p` 出栈时，它的左右孩子刚被压入栈、位于栈顶附近，因此 `p` 的所有后代一定在 `p` 之后被处理，且都在「比 `p` 更早入栈的祖先的其它分支」之前被处理——这正是前序「根、左子树、右子树」的顺序。

另一种等价写法是**沿左链一路下行**：把当前节点的右孩子压栈、输出当前节点、然后 `cur = cur->left`，走到底再弹栈；两种写法时间空间同阶，第一种更短。

## 复杂度

- 时间：`O(n)`，每个节点入栈、出栈各一次
- 空间：`O(h)`（`h` 为树高，栈中最多存放一条「尚未处理的右分支」集合），最坏 `O(n)`

## 关键点

- **入栈顺序必须是先右后左**，写反了就变成「根 → 右 → 左」
- 空树要单独处理（不压栈 / 输出空行），否则访问 `root->val` 会崩
- 用 `vector` 当栈比 `std::stack` 更快也更省事（`push_back` / `pop_back` / `back`）
- 节点的值可能重复、可能为负数，不能靠值来判断是否访问过
- 若要写通用迭代模板（前/中/后序统一的「标记法」），注意前序里「访问节点」和「压入孩子」的顺序容易写反
