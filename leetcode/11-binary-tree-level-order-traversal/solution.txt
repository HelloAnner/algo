[思路]
BFS + 队列（文档里的 Java 解法就是这个）。

1. 把根节点入队。
2. 只要队列非空，就先记下当前队列的长度 size，这就是这一层的节点个数。
3. 连续弹出 size 个节点：把它们的值依次放进这一层的答案，同时把非空的左右孩子入队。这 size 个节点处理完后，队列里剩下的恰好就是下一层的全部节点。
4. 重复 2、3 直到队列为空。

关键在于「先取 size 再循环」：如果在循环里边弹边用 queue.size() 当边界，队列入队新节点后 size 会变大，就会把下一层的节点混进当前层。也可以用一个变量记录层数、按层号写入答案，效果一样。

用 ASCII 示意每一轮队列里装的是什么（以示例 1 为例）：

    round 1: [3]            -> 输出 3，入队 9、20
    round 2: [9, 20]        -> 输出 9 20，入队 15、7
    round 3: [15, 7]        -> 输出 15 7，无孩子入队
    round 4: []             -> 结束

[复杂度]
时间：O(N)，每个节点入队、出队各一次
空间：O(W)，W 为树的最大宽度（队列里最多同时存一层节点）；最坏（满二叉树）为 O(N)

[关键点]
- 必须先保存 size = q.size()，再在循环里弹出正好 size 个节点
- 只有非空孩子才入队，否则空指针会被当成节点访问
- 建树时下标 i 的父节点是 (i-1)/2，i 为奇数接在父节点左边、偶数接在右边；数组里的 -1 既不入队也不要建节点
- 输出是「每层一行」，注意行尾不要多输出空格，也不要少输出换行
- 树可能退化成链，递归 DFS 写法在极端情况下有栈溢出风险，BFS 没有这个问题（文档也提到 DFS 可以但没必要）

[C++ 代码]
// 二叉树的层序遍历
// https://leetcode.cn/problems/binary-tree-level-order-traversal/
//
// 思路：按层序数组建树，BFS 时先记下当前队列长度，一次处理完一整层。
// 复杂度：时间 O(N) 空间 O(W)（W 为最大宽度）
#include <iostream>
#include <queue>
#include <vector>

using namespace std;

struct Node {
    int val = 0;
    Node *left = nullptr;
    Node *right = nullptr;
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n = 0;
    if (!(cin >> n)) return 0;

    vector<Node> nodes(n);
    for (int i = 0; i < n; ++i) cin >> nodes[i].val;

    // 层序数组：下标 i 的孩子是 2i+1 / 2i+2，-1 表示空节点
    for (int i = 1; i < n; ++i) {
        if (nodes[i].val == -1) continue;
        int parent = (i - 1) / 2;
        if (i % 2 == 1) {
            nodes[parent].left = &nodes[i];
        } else {
            nodes[parent].right = &nodes[i];
        }
    }

    queue<Node *> q;
    if (n > 0 && nodes[0].val != -1) q.push(&nodes[0]);

    while (!q.empty()) {
        size_t size = q.size();  // 当前这一层的节点个数
        for (size_t i = 0; i < size; ++i) {
            Node *cur = q.front();
            q.pop();
            if (i > 0) cout << ' ';
            cout << cur->val;
            if (cur->left) q.push(cur->left);
            if (cur->right) q.push(cur->right);
        }
        cout << '\n';
    }
    return 0;
}
