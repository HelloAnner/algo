题目：最长连续序列
链接：https://leetcode.cn/problems/longest-consecutive-sequence/
难度：中等

[题目描述]

给定一个未排序的整数数组 nums，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度，要求算法的时间复杂度为 O(n)。

这里的「连续」指数值上依次相差 1（例如 1, 2, 3, 4）。数组中重复出现的元素只算一次。

示例 1（nums = [100, 4, 200, 1, 3, 2]）的查找过程：

    所有数字入集合：{1, 2, 3, 4, 100, 200}

    逐个判断是不是「起点」（起点 = x - 1 不在集合里）：

      x = 100 : 99  不在集合 -> 是起点，向后数 100              长度 1
      x =   4 : 3   在集合   -> 不是起点，跳过（属于 1 开头那段）
      x = 200 : 199 不在集合 -> 是起点，向后数 200              长度 1
      x =   1 : 0   不在集合 -> 是起点，向后数 1 -> 2 -> 3 -> 4  长度 4  <- 答案
      x =   3 : 2   在集合   -> 跳过
      x =   2 : 1   在集合   -> 跳过

    数轴上的连续段：

        1 --- 2 --- 3 --- 4        长度 4（最长）
      100                          长度 1
      200                          长度 1

如果省掉「x - 1 不在集合里」这一步判断，每个元素都要向后数一遍（1 数一次、2 再数一次、3 再数一次……），最坏会退化到 O(n^2)：这正是本题要求 O(n) 时最容易踩的坑。

[输入格式]

第一行一个整数 n，表示数组长度。
第二行 n 个整数 nums[0..n-1]，相邻数字用空格分隔。

[输出格式]

输出一个整数，表示最长连续序列的长度。

[示例 1]
输入：
6
100 4 200 1 3 2
输出：
4
解释：最长连续序列是 [1, 2, 3, 4]，它的长度为 4。

[示例 2]
输入：
10
0 3 7 2 5 8 4 6 0 1
输出：
9
解释：最长连续序列是 [0, 1, 2, 3, 4, 5, 6, 7, 8]，长度为 9；数字 0 出现了两次，只算一次。

[示例 3]
输入：
0
输出：
0
解释：数组为空，最长连续序列长度为 0。

[数据范围]

- 0 <= n <= 10^5
- -10^9 <= nums[i] <= 10^9
- 要求时间复杂度 O(n)（哈希表平均 O(1)，所以下面的做法满足要求）
