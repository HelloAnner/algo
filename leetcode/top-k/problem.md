## 题目描述

返回一个数组中前 `k` 个大的（或者前 `k` 个小的）数字。

输入里用 `type` 指定方向：`type = 0` 求前 `k` 大，`type = 1` 求前 `k` 小。

（文档 67 节只写了这一句，没有原题链接和样例，这里把它定义成可判题的 ACM 形式。）

## 输入格式

第一行三个整数 `n`、`k`、`type`：

- `n`：数组长度；
- `k`：要取出的元素个数；
- `type`：`0` 表示取前 `k` 大，`1` 表示取前 `k` 小。

第二行 `n` 个整数 `a[0..n-1]`，相邻数字用空格分隔。

## 输出格式

一行 `k` 个整数，相邻数字用空格分隔：

- `type = 0`：按**从大到小**输出前 `k` 大的数；
- `type = 1`：按**从小到大**输出前 `k` 小的数。

重复元素按出现次数各算一个，不做去重。

## 示例

### 示例 1

输入：
```
5 2 0
3 1 4 1 5
```

输出：
```
5 4
```

解释：前 2 大的数是 `5` 和 `4`，按从大到小输出。

### 示例 2

输入：
```
6 3 1
3 1 4 1 5 9
```

输出：
```
1 1 3
```

解释：前 3 小的数是 `1`、`1`、`3`（重复的 `1` 各算一个），按从小到大输出。

### 示例 3

输入：
```
4 4 0
2 2 2 2
```

输出：
```
2 2 2 2
```

解释：`k = n` 时就是整个数组从大到小输出，全部元素相同也要输出 `k` 个。

## 数据范围

- `1 <= k <= n <= 10^5`
- `-10^4 <= a[i] <= 10^4`

## 提示

- 直接排序后取头/尾 `k` 个可以得到 `O(n log n)` 的做法；用堆可以做到 `O(n log k)`。
