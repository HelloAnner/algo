题目：下一个更大元素 III
链接：https://leetcode.cn/problems/next-greater-element-iii/
难度：中等

[题目描述]
给你一个 32 位正整数 n，你需要找到最小的 32 位整数，它与 n 中存在的位数完全相同（即由相同的数字重新排列而成），并且其值严格大于 n。如果不存在这样的 32 位整数，则返回 -1。

求「下一个排列」的三步示意（以 n = 1234 为例）：

   数字      1    2    3    4
                         ^    ^
                      pivot   从右往左第一个升序对是 3 < 4

   第 1 步  从右往左找第一个升序对 n[i-1] < n[i]，记 pivot = i - 1；找不到说明已经是最大排列，输出 -1
   第 2 步  pivot 之后的后缀一定是非递增的，从右往左找第一个大于 n[pivot] 的数字，与 n[pivot] 交换
   第 3 步  把 pivot 之后的后缀反转成非递减，后缀就变成它能组成的最小数

再以 n = 230241 为例（答案是 230412）：

   下标      0    1    2    3    4    5
   数字      2    3    0    2    4    1
                            ^    ^
                         pivot   后缀里从右往左第一个大于 2 的是 4

   交换 n[3] 与 n[4]：   2    3    0    4    2    1
   反转后缀 [4..5]：     2    3    0    4    1    2   ->  230412

[输入格式]
一行一个 32 位正整数 n。

[输出格式]
输出一行一个整数：满足条件的最小整数；不存在则输出 -1。

[示例 1]
输入：
12
输出：
21
解释：由数字 1、2 组成且比 12 大的最小整数是 21。

[示例 2]
输入：
21
输出：
-1
解释：21 已经是 2、1 能组成的最大数（数字从右往左看一直是非递减的），不存在更大的排列，返回 -1。

[示例 3]
输入：
1234
输出：
1243
解释：从右往左第一个升序对是 3 < 4，把 3 和 4 交换后后缀只剩一个字符，得到 1243。

[示例 4]
输入：
1999999999
输出：
-1
解释：它的下一个排列是 9199999999，超过了 32 位有符号整数的上限 2147483647，所以返回 -1。

[数据范围]
- 1 <= n <= 2^31 - 1
- 结果必须落在 32 位有符号整数范围内，否则输出 -1

[备注]
原文档这一节叫「输出下一个更大的数字」，对应 LeetCode 556. 下一个更大元素 III（https://leetcode.cn/problems/next-greater-element-iii/）。
