## 题目描述

请你用**链表**实现一个栈（后进先出），支持下面几种操作：

- `push x`：把整数 `x` 压入栈顶
- `pop`：弹出栈顶元素，并输出它的值
- `top`：输出栈顶元素的值（不弹出）
- `empty`：输出栈是否为空（`true` / `false`）
- `size`：输出当前栈里元素的个数

这是字节面试里出现过的手写题（文档第 84 题）。文档给的 Java 版本用双向链表 + 尾指针实现；用单链表 + 头插法也能做到所有操作 O(1)，而且代码更简单。

## 输入格式

第一行一个整数 `q`，表示操作个数。
接下来 `q` 行，每行一个操作，格式如上：`push` 后面跟一个整数 `x`，其余操作单独成行。

题目保证 `pop` / `top` 不会在空栈上调用。

## 输出格式

对每个 `pop` / `top` / `empty` / `size` 操作，按出现顺序**逐行**输出结果；
`push` 不产生输出。

## 示例

### 示例 1

输入：
```
7
push 1
push 2
top
pop
top
empty
pop
```

输出：
```
2
2
1
false
1
```

解释：依次压入 1、2，栈顶是 2；`pop` 弹掉 2，栈顶变成 1；此时栈不空（`false`）；再 `pop` 弹掉 1。

### 示例 2

输入：
```
3
empty
push 5
top
```

输出：
```
true
5
```

解释：一开始是空栈，`empty` 输出 `true`；压入 5 之后栈顶就是 5。

### 示例 3

输入：
```
4
push 3
push 4
size
pop
```

输出：
```
2
4
```

解释：栈里有 3、4 两个元素（栈顶是 4），`size` 输出 2；`pop` 输出并弹掉栈顶的 4。

## 数据范围

- `1 <= q <= 10^5`
- `-10^9 <= x <= 10^9`
- 保证 `pop` / `top` 时栈非空
- 进阶：`push` / `pop` / `top` / `empty` / `size` 都要 O(1)，空间 O(栈内元素个数)
