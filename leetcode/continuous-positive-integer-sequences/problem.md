## 题目描述

输入一个正整数 `target`，输出所有和为 `target` 的**连续正整数序列**（每个序列至少含有两个数）。

序列内的数字由小到大排列，不同序列按照首个数字从小到大排列。

## 输入格式

一行一个整数 `target`。

## 输出格式

第一行一个整数 `k`，表示满足条件的序列个数。
接下来 `k` 行，每行一个序列：序列中的数字由小到大、用空格分隔，行尾不留多余空格。
`k = 0` 时只输出一行 `0`。

## 示例

### 示例 1

输入：
```
9
```

输出：
```
2
2 3 4
4 5
```

解释：`2 + 3 + 4 = 9`，`4 + 5 = 9`；首项 2 < 4，所以按这个顺序输出。

### 示例 2

输入：
```
15
```

输出：
```
3
1 2 3 4 5
4 5 6
7 8
```

解释：`1+2+3+4+5 = 15`，`4+5+6 = 15`，`7+8 = 15`。

### 示例 3

输入：
```
2
```

输出：
```
0
```

解释：两个连续正整数的最小和是 `1 + 2 = 3 > 2`，所以没有合法序列。

## 数据范围

- `1 <= target <= 10^5`
