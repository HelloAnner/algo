## 题目描述

给你一个包含 `n` 个整数的数组 `nums`，判断 `nums` 中是否存在三个元素 `a`、`b`、`c`，使得 `a + b + c = 0`？请你找出所有和为 `0` 且**不重复**的三元组。

注意：答案中不可以包含重复的三元组。

## 输入格式

第一行一个整数 `n`。
第二行 `n` 个整数 `nums[0..n-1]`，相邻数字用空格分隔。

## 输出格式

输出所有满足条件的不重复三元组：

- 每个三元组占一行，组内三个数按**升序**用空格分隔；
- 所有行按**字典序**排列（先比第一个数，再比第二个数，最后比第三个数）；
- 若不存在这样的三元组，输出一个空行。

## 示例

### 示例 1

输入：
```
6
-1 0 1 2 -1 -4
```

输出：
```
-1 -1 2
-1 0 1
```

解释：满足条件的三元组是 `(-1, 0, 1)` 和 `(-1, -1, 2)`；按字典序先输出 `-1 -1 2`。

### 示例 2

输入：
```
3
0 1 1
```

输出：
```

解释：不存在和为 `0` 的三元组，输出一个空行。

### 示例 3

输入：
```
5
0 0 0 0 0
```

输出：
```
0 0 0
```

解释：去重之后只输出一个 `(0, 0, 0)`。

## 数据范围

- `3 <= n <= 3000`
- `-10^5 <= nums[i] <= 10^5`

## 提示

- `O(n^3)` 的暴力枚举会超时，正解是 `O(n^2)` 的「排序 + 双指针」。
