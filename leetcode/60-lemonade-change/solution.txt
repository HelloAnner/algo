[思路]

贪心：只需要记录手里 5 元和 10 元的张数（20 元找不出去，不用记）。

- 收到 5 元：five++；
- 收到 10 元：必须找出一张 5 元 —— ten++、five--，five < 0 就失败；
- 收到 20 元：需要找 15 元，优先用 10 + 5（把大额钞票先花出去，5 元更灵活），没有 10 元才用 3 张 5 元。

文档里 Java 代码就是这个逻辑：if (cash[1] > 0) { 10 + 5 } else { 3 * 5 }。区别只在于它额外用 cash[2] 统计了 20 元的张数，而 20 元永远不会被当成零钱找出去，可以省掉。

[复杂度]

时间：O(n)   空间：O(1)

一次遍历；只维护 five / ten 两个计数器。

[关键点]

- 找零是贪心：能找 10 + 5 就不要找 3 张 5 元，因为 5 元更通用（付 10 元的顾客只能用它找）
- five 变成负数就立刻返回 false，不用继续
- 20 元的面额不用统计
- n = 0 是合法输入，直接输出 true

[C++ 代码]
// 柠檬水找零（LeetCode 860. Lemonade Change）
// https://leetcode.cn/problems/lemonade-change/
//
// 思路：贪心。只记 5 元和 10 元的张数：收 10 元找 1 张 5 元；
//       收 20 元优先找 10 + 5，不够再找 3 张 5 元。找不开就失败。
// 复杂度：时间 O(n) 空间 O(1)
#include <iostream>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    if (!(cin >> n)) return 0;

    int five = 0;  // 手里的 5 元张数
    int ten = 0;   // 手里的 10 元张数（20 元永远不用找出去，不必统计）
    for (int i = 0; i < n; ++i) {
        int bill;
        cin >> bill;
        if (bill == 5) {
            ++five;
        } else if (bill == 10) {
            ++ten;
            --five;  // 找出一张 5 元
            if (five < 0) {
                cout << "false" << '\n';
                return 0;
            }
        } else {  // 20 元，需要找 15 元
            if (ten > 0) {
                --ten;
                --five;
            } else {
                five -= 3;
            }
            if (five < 0) {
                cout << "false" << '\n';
                return 0;
            }
        }
    }

    cout << "true" << '\n';
    return 0;
}
