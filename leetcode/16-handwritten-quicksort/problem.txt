题目：手写快速排序
链接：https://leetcode.cn/problems/sort-an-array/
难度：中等

[题目描述]

手写快速排序：给定一个整数数组，把它按升序排序后输出。不允许调用库排序函数（如 std::sort），必须自己实现快排。

快排是分治思想：选一个基准元素（pivot），把数组划分成「不大于基准」和「不小于基准」两部分，使基准归位，再对左右两部分递归排序，最终整体有序。实现上通常用头尾双指针完成一趟划分。

一趟划分的示意（Hoare 头尾双指针，这里基准值 pivot 取 5）：

     下标:    0    1    2    3    4
     值:      5    2    9    1    5
              i->              <-j
      i 从 low - 1 出发往右走，j 从 high + 1 出发往左走

     第 1 轮：++i 停在 0（arr[0] = 5，不再小于 pivot），
              --j 停在 4（arr[4] = 5，不再大于 pivot），
              i < j，交换 arr[0] 与 arr[4]（两个 5 互换，数组看起来没变）

     第 2 轮：++i 走过 2，停在 2（arr[2] = 9），
              --j 停在 3（arr[3] = 1），
              i < j，交换 arr[2] 与 arr[3]：

     下标:    0    1    2    3    4
     值:      5    2    1    9    5

     第 3 轮：++i 停在 3（9），--j 停在 2（1），
              此时 i >= j，划分结束，返回 j = 2

     于是递归处理 [0, 2] 和 [3, 4] 两段，两段合起来正好覆盖整个区间。

注意内层循环用的是严格不等号：arr[i] < pivot 才继续往右，arr[j] > pivot 才继续往左。等于基准的元素也要停下来参与交换，否则全是相同元素的数组会退化。

[输入格式]
第一行一个整数 n，表示数组长度。
第二行 n 个整数 a[0..n-1]，相邻数字用空格分隔。

[输出格式]
一行，n 个整数，按升序排列，相邻数字用空格分隔。

[示例 1]
输入：
5
5 2 9 1 5
输出：
1 2 5 5 9
解释：含重复元素 5，排序后两个 5 相邻；重复元素不需要稳定，位置可以互换。

[示例 2]
输入：
6
3 3 3 1 2 0
输出：
0 1 2 3 3 3
解释：大量重复元素是快排最容易退化的场景之一，实现时要保证划分仍然均衡。

[数据范围]
- 1 <= n <= 5 * 10^4
- -5 * 10^4 <= a[i] <= 5 * 10^4
- 要求平均（期望）时间复杂度 O(n log n)，额外空间 O(log n) 递归栈
