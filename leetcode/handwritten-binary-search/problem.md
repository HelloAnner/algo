## 题目描述

手写二分查找：给定一个按非递减顺序排列的整数数组 `nums` 和一个目标值 `target`，用二分查找找出 `target` 在数组中**第一次**出现的下标（下标从 0 开始）；如果数组中不存在 `target`，输出 `-1`。

要求时间复杂度 O(log n)，不允许从头到尾线性扫描。

（原文档第 41 节是一道口头题：「介绍下二分查找，如果我想在链表中使用二分查找，怎么做比较好？」这里把它抽成可判题的手写二分版本，关于链表的追问见 [`solution.md`](./solution.md)。）

## 输入格式

第一行一个整数 `n`，表示数组长度。
第二行 `n` 个整数 `nums[0..n-1]`，非递减排列，相邻数字用空格分隔。
第三行一个整数 `target`。

## 输出格式

一个整数：`target` 第一次出现的下标；不存在则输出 `-1`。

## 示例

### 示例 1

输入：
```
7
-3 0 5 9 9 12 20
9
```

输出：
```
3
```

解释：`9` 在下标 3 和 4 都出现，要返回第一次出现的下标 3。

### 示例 2

输入：
```
7
-3 0 5 9 9 12 20
6
```

输出：
```
-1
```

解释：数组中不存在 6。

### 示例 3

输入：
```
1
7
7
```

输出：
```
0
```

解释：只有一个元素且正好命中。

## 数据范围

- `1 <= n <= 10^5`
- `-10^9 <= nums[i], target <= 10^9`
- `nums` 按非递减顺序排列
