## 题目描述

给定一棵二叉树的根节点 `root` 和一个整数目标和 `targetSum`，找出所有**从根节点到叶子节点**路径总和等于 `targetSum` 的路径。

**叶子节点**是指没有子节点的节点。

## 输入格式

第一行：二叉树的层序序列（LeetCode 风格），节点值之间用空格分隔，空节点用 `null` 表示，末尾多余的 `null` 可以省略；如果树为空，这一行只有一个 `null`。
第二行：一个整数 `targetSum`。

## 输出格式

第一行输出一个整数 `k`，表示满足条件的路径条数。
接下来 `k` 行，每行输出一条路径上的节点值，从根到叶子、用空格分隔。
路径之间按「先左子树、后右子树」的 DFS 顺序输出；`k = 0` 时只输出一行 `0`。

## 示例

### 示例 1

输入：
```
5 4 8 11 null 13 4 7 2 null null 5 1
22
```

输出：
```
2
5 4 11 2
5 8 4 5
```

解释：`5 -> 4 -> 11 -> 2` 与 `5 -> 8 -> 4 -> 5` 的路径和都是 22。

### 示例 2

输入：
```
1 2 3
5
```

输出：
```
0
```

解释：两条根到叶子的路径 `1 -> 2`（和为 3）、`1 -> 3`（和为 4）都不等于 5，没有符合条件的路径。

## 数据范围

- 树中节点数 `0 <= n <= 5000`
- `-1000 <= Node.val <= 1000`
- `-1000 <= targetSum <= 1000`
