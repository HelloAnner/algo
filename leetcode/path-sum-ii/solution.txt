[思路]
DFS + 回溯：维护一条当前路径 path 和一个剩余目标和 remain。

1. 进入节点时 remain -= node.val，并把 node.val 压入 path；
2. 如果该节点是叶子且 remain == 0，就把当前 path 拷贝一份存进答案；
3. 递归左右子树；
4. 离开节点时 path.pop_back()，把状态还原，交给兄弟分支继续使用。

和文档里 Java 解法的区别只在实现细节：Java 每次递归都 new ArrayList<>(list) 复制一份路径，这里改成「一份 path + 回溯」，每个节点只入栈出栈一次，省掉了每层的复制。

为什么必须等到叶子：题目要求路径从根一直延伸到叶子，和等于目标值的内部节点不能算答案。节点值可以是负数，所以不能靠「remain 小于 0」剪枝，只能老老实实搜到底。

[复杂度]
时间：O(n^2)   空间：O(h)

DFS 本身是 O(n)，但答案里每条路径最长 O(n)，把它们拷进结果的总代价是「所有答案路径长度之和」，最坏是链状树上的 O(n^2)（输出规模本身也有这么大）；空间上 path 和递归栈都只占树高 h，结果数组不计入。

[关键点]
- 记录答案时要拷贝 path，不能存引用——回溯会把内容改掉
- 只有「叶子且 remain == 0」才记录，和等于目标的内部节点不算
- 空树返回空结果，输出 0；注意不要对空指针解引用
- 回溯要成对：path.push_back 对应 path.pop_back；remain 用值传递，天然还原
- 节点值可以是负数，不能剪枝
- 输出时先打印条数，再逐行打印路径，行内用空格分隔、行尾不留多余空格

[C++ 代码]
// 路径总和 II
// https://leetcode.cn/problems/path-sum-ii/
//
// 思路：DFS + 回溯，维护当前路径 path 和剩余目标和 remain，在叶子且 remain == 0 时记录答案。
// 复杂度：时间 O(n^2)（拷贝路径） 空间 O(h)，h 为树高
#include <iostream>
#include <queue>
#include <sstream>
#include <string>
#include <vector>

using namespace std;

struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    explicit TreeNode(int v) : val(v), left(nullptr), right(nullptr) {}
};

// 按 LeetCode 层序序列建树，空节点写作 null
TreeNode *buildTree(const vector<string> &tokens) {
    if (tokens.empty() || tokens[0] == "null") return nullptr;
    TreeNode *root = new TreeNode(stoi(tokens[0]));
    queue<TreeNode *> q;
    q.push(root);
    size_t i = 1;
    while (!q.empty() && i < tokens.size()) {
        TreeNode *cur = q.front();
        q.pop();
        if (tokens[i] != "null") {
            cur->left = new TreeNode(stoi(tokens[i]));
            q.push(cur->left);
        }
        ++i;
        if (i < tokens.size()) {
            if (tokens[i] != "null") {
                cur->right = new TreeNode(stoi(tokens[i]));
                q.push(cur->right);
            }
            ++i;
        }
    }
    return root;
}

void dfs(TreeNode *node, long long remain, vector<int> &path, vector<vector<int>> &res) {
    if (node == nullptr) return;
    remain -= node->val;
    path.push_back(node->val);
    if (node->left == nullptr && node->right == nullptr && remain == 0) {
        res.push_back(path);  // 拷贝一份当前路径
    } else {
        dfs(node->left, remain, path, res);
        dfs(node->right, remain, path, res);
    }
    path.pop_back();  // 回溯
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string line;
    if (!getline(cin, line)) return 0;

    vector<string> tokens;
    istringstream iss(line);
    for (string tok; iss >> tok;) tokens.push_back(tok);

    long long targetSum = 0;
    cin >> targetSum;

    vector<vector<int>> res;
    vector<int> path;
    dfs(buildTree(tokens), targetSum, path, res);

    cout << res.size() << '\n';
    for (const auto &p : res) {
        for (size_t i = 0; i < p.size(); ++i) {
            if (i > 0) cout << ' ';
            cout << p[i];
        }
        cout << '\n';
    }
    return 0;
}
