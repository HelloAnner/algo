## 题目描述

给定一个字符串 `s`，逐个翻转字符串中的每个单词。

单词是由非空格字符组成的序列，`s` 中相邻单词之间至少有 1 个空格。请返回单词顺序翻转后的字符串：单词之间用单个空格连接，且不含前导空格和尾随空格。

## 输入格式

一行字符串 `s`（整行读入，可能包含前导空格、尾随空格，以及单词之间的多个空格）。

## 输出格式

一行字符串：单词顺序翻转，单词之间恰好一个空格，首尾没有空格。

## 示例

### 示例 1

输入：
```
the sky is blue
```

输出：
```
blue is sky the
```

解释：四个单词按逆序输出。

### 示例 2

输入（`hello` 前和 `world!` 后各有两个空格）：
```
  hello world!  
```

输出：
```
world! hello
```

解释：输入可以在前面或后面包含多余的空格，但输出不能包含。

### 示例 3

输入（`good` 和 `example` 之间有 3 个空格）：
```
a good   example
```

输出：
```
example good a
```

解释：单词之间多余的空格在输出中被压缩成 1 个。

## 数据范围

- `1 <= s.length <= 10^4`
- `s` 只包含英文字母、数字和空格
- `s` 中至少存在一个单词
