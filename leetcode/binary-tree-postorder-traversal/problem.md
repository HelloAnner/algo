## 题目描述

给定一棵二叉树，返回它的**后序遍历**（左 → 右 → 根）。

**进阶**：递归写法很简单，请用**迭代（非递归）**的方式完成，不要用递归。

后序遍历顺序：先遍历左子树，再遍历右子树，最后访问根节点。

## 输入格式

按**层序**（LeetCode 的数组表示）给出二叉树的节点，token 之间用空白（空格或换行）分隔：

- 整数表示一个节点值；
- `null`（小写）表示该位置是空节点；
- 第一个 token 是根节点，之后按层序依次为「每个非空节点给出它的左孩子、右孩子」；
- 空树用单独的 `null` 表示（或输入为空）。

例如 `1 null 2 3` 表示：根为 1，左孩子为空，右孩子为 2，节点 2 的左孩子为 3。

## 输出格式

一行，按后序遍历的顺序输出各节点的值，相邻数字之间用一个空格分隔。

如果树为空，输出一个空行。

## 示例

### 示例 1

输入：
```
1 null 2 3
```

输出：
```
3 2 1
```

解释：树为 1 → 右孩子 2，2 → 左孩子 3。后序遍历先访问 3，再访问 2，最后访问根 1，所以输出 `3 2 1`。

### 示例 2

输入：
```
1 2 3 4 5 null 6
```

输出：
```
4 5 2 6 3 1
```

解释：根 1 的左右孩子是 2、3；2 的左右孩子是 4、5；3 的左孩子为空、右孩子是 6。后序顺序为 4、5、2、6、3、1。

### 示例 3

输入：
```
7
```

输出：
```
7
```

解释：只有一个节点，它既是根也是后序遍历的唯一元素。

## 数据范围

- 节点个数 `n` 满足 `0 <= n <= 100`（空树也是合法输入）
- `-100 <= Node.val <= 100`
- 输出序列的长度恰好等于节点个数
