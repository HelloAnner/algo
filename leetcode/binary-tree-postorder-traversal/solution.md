## 思路

后序遍历 = 左 → 右 → 根。递归照定义写很简单，但题目要求迭代，这里用一个「前序变形 + 整体反转」的技巧：

1. 前序遍历是「根 → 左 → 右」：入栈时先压右孩子、再压左孩子，出栈顺序就是「根 → 左 → 右」。
2. 把入栈顺序改成**先压左孩子、再压右孩子**，出栈顺序就变成了「根 → 右 → 左」。
3. 把这个序列**整体反转**，得到的正好是「左 → 右 → 根」，也就是后序遍历。

具体流程：

- 栈里先压入根节点；
- 每次弹出栈顶 `p`，把 `p->val` 追加到答案数组尾部；
- 再依次把 `p->left`、`p->right` 压栈（左先入栈，右后入栈，这样右孩子先出栈）；
- 栈空后，把答案数组 `reverse` 一次即可。

文档里的 Java 解法用 `LinkedList.addFirst`（头插）实现，等价于「先尾插、最后反转」；C++ 里用 `vector` + `std::reverse` 更省事，也避免了链表节点的开销。

另一种等价写法是「双栈法」或「栈中记录节点是否已访问」的标记法，本质都是保证根节点在左右孩子之后输出。

## 复杂度

- 时间：O(n)，每个节点入栈、出栈、写入答案各一次，最后整体反转一次
- 空间：O(n)，显式栈与答案数组各 O(n)

## 关键点

- **压栈顺序不能写反**：必须「先左后右」压栈，出栈才是「右、左」，反转后才符合后序；写成「先右后左」就退化成前序遍历的镜像
- 反转是**整个数组反转一次**，不是在每个子树内部各反转一次
- 空树要输出空行（题目允许 `n = 0`），注意不要多输出空格
- 本题输入是 LeetCode 的层序数组表示，建树时要按「每个非空节点依次消耗左、右两个孩子 token」来解析，`null` 只是占位、不入队
- 别用递归：题目要求迭代，而且深链状树容易爆栈
