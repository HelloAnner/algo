# 二叉树的锯齿形层序遍历 · 解法

## 思路

**BFS 逐层处理 + 按层号决定是否反转**。

1. 用普通层序遍历（队列）拿到每一层的节点值，方法同 LC 102：每轮先记下队列长度 size，一次处理完整层。
2. 用一个变量 level 记录当前层号（根为第 0 层）：
   - level 为偶数：这一层保持从左到右的顺序；
   - level 为奇数：把这一层的数组反转后再输出。
3. level 自增，直到队列为空。

文档里 Java 版尝试用「队列 + 栈」交替来模拟方向，思路本身可以，但入栈/出栈顺序稍不留神就会把下面两层的顺序也弄反（文档作者自己也说「想想看哪里有问题」）。**先按正常层序取整层、再按需反转**最不容易错；文档给出的 DFS 版本（偶数层 push_back、奇数层头插）也是同一个效果。

## 复杂度

- 时间：O(N)，每个节点只进出队一次，每层最多再反转一次（合计 O(N)）
- 空间：O(W)，W 为树的最大宽度；最坏（满二叉树）为 O(N)

## 关键点

- 方向只取决于**层号**，与节点自身的左右孩子无关；入队时永远先左后右，反转只发生在输出这一层时
- 判断奇偶用 `level % 2 == 1` 表示「需要反转」，根层是第 0 层（不反转）
- 必须先保存 `size = q.size()` 再处理整层，否则下一层节点会混进来
- 只有非空孩子才入队；层序数组里的 -1 不建节点
- 输出格式：每层一行、行内空格分隔，行尾不能有多余空格
- 树可能退化成链，BFS 写法不会有递归栈溢出的问题
