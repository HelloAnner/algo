# 二叉树的锯齿形层序遍历

- **来源**：https://leetcode.cn/problems/binary-tree-zigzag-level-order-traversal/
- **难度**：中等

## 题目描述

给定一棵二叉树，返回其节点值的**锯齿形层序遍历**：先从左往右遍历第一层，再从右往左遍历第二层，第三层再从左往右……层与层之间交替进行。

## 输入格式

第一行一个整数 n，表示层序数组的长度。
第二行 n 个整数，为二叉树的**层序（BFS）序列**，其中 -1 表示空节点（null）。

序列构造方式与 LeetCode 相同：按下标 i 从 0 开始依次填节点，下标 i 的左右孩子分别是 2i+1 和 2i+2；某个位置是 -1 表示该位置没有节点（它的孩子也不会出现在数组里），数组末尾连续的 -1 可以省略。

因为用 -1 表示空节点，所以本题保证节点值都是非负整数。

## 输出格式

每一层输出一行：

- 第 0 层（根所在层）从左到右；
- 第 1 层从右到左；
- 第 2 层从左到右……以此类推，奇数层反向。

相邻数字用空格分隔。树保证非空，至少输出一行。

## 示例

### 示例 1

输入：
```text
7
3 9 20 -1 -1 15 7
```

输出：
```text
3
20 9
15 7
```

解释：第一层 [3] 从左到右；第二层本来的顺序是 9、20，反转后输出 20 9；第三层是 15、7，仍从左到右。

### 示例 2

输入：
```text
1
1
```

输出：
```text
1
```

解释：只有根节点一层。

### 示例 3

输入：
```text
7
1 2 3 4 -1 -1 5
```

输出：
```text
1
3 2
4 5
```

解释：第二层原本是 2、3，反向输出 3 2；第三层是 4、5，保持从左到右。

## 数据范围

- 1 <= 节点个数 <= 2000
- 1 <= n <= 4000（层序数组长度，含 -1 占位）
- 0 <= 节点值 <= 1000（因此可以用 -1 表示空节点）
- 树的深度不超过 1000，允许退化成一条链的极端形状
