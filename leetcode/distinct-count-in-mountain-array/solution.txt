[思路]

分两步：先从左边找到峰顶，再从峰顶向两侧双指针归并并去重计数。

第一步，找峰顶。从左往右扫，只要 nums[i] <= nums[i+1] 就继续，停下时的下标 peak 就是非递减前缀的最后一个位置。用 <=（而不是 <）是为了把相等的平台整体划到左段，这样平台上的元素不会同时出现在两段里。

  4 |                    *   <- 峰顶
  3 |              *           *
  2 |        *                       *
  1 |  *                                   *
    +-----+-----+-----+-----+-----+-----+-----+> 下标
       0     1     2     3     4     5     6
                        ^
                  左段 <- peak | peak+1 -> 右段
        nums[peak], nums[peak-1], ..., nums[0]      向左看是非递增的
        nums[peak+1], nums[peak+2], ..., nums[n-1]   向右看也是非递增的

第二步，从峰顶向两侧归并。用双指针 i = peak（向左走）、j = peak + 1（向右走），每步取两边当前值的较大者输出，并与上一次输出的值比较，不同才让答案 +1。指针越界时用一个比所有可能值都小的哨兵代替。

  以 nums = 1 2 3 4 3 2 1 为例：
    左段（从 peak 向左读）：4 3 2 1
    右段（从 peak+1 向右读）：3 2 1
    归并（每步取两边较大者）：4 3 3 2 2 1 1
    去重（只和上一个输出比较）：4 3 2 1  -> 共 4 个不同值

正确性：两段都非递增，取较大者保证输出序列非递增；数组中的每个数值都出现在某一侧，所以一定会在某一步被输出；对非递增序列做「与上一个输出比较」的线性去重，统计出的正是不同数值的个数。因为每步只移动一个指针，总步数是 O(n)。

注意文档给出的 Java 代码在 nums[left] < nums[right] / else 两个分支里直接 res++，没有和上一次的值去重，遇到「同一数值在两侧先后出现」时会重复计数；统一成「先取较大者、再统一去重」就没有这个问题。

[复杂度]
时间：O(n)（找峰顶 O(n)，双指针每步只移动一个指针，合计 O(n)）   空间：O(1)（除读入的数组外不使用额外空间）

[关键点]

- 找峰顶用 <=：把相等平台划到左段，保证两段都是非递增的；用 < 会让平台元素同时属于两段而重复计数
- 去重要和上一次输出的值比较，不能只在同一侧内部比较
- 数值可能是负数甚至 -10^9，哨兵不能想当然用 -1，要么用 bool first 标记，要么用足够小的值
- 边界：n == 1、纯递增、纯递减、全相等都要能过；纯递增时峰顶在最右端，右段为空，靠哨兵兜底
- 每步必须只推进一个指针，否则会漏掉元素；两值相等时随便取一个，另一个会在下一步被去重跳过

[C++ 代码]
// 找出不重复的元素个数（山峰数组的不同值计数）
// https://www.nowcoder.com/discuss/425581
//
// 思路：先线性找到峰顶，再从峰顶向两侧双指针归并（两侧都非递增）并去重计数。
// 复杂度：时间 O(n) 空间 O(1)
#include <iostream>
#include <vector>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    if (!(cin >> n) || n <= 0) {
        cout << 0 << '\n';
        return 0;
    }

    vector<long long> nums(n);
    for (auto &x : nums) cin >> x;

    // 非递减前缀的最后一个下标；相等平台取最右端，保证两侧都是非递增
    int peak = 0;
    while (peak + 1 < n && nums[peak] <= nums[peak + 1]) ++peak;

    const long long NEG = -4000000000000000000LL;  // 比任何输入都小的哨兵
    int i = peak, j = peak + 1;
    long long last = 0;
    bool first = true;
    int count = 0;

    while (i >= 0 || j < n) {
        long long a = (i >= 0 ? nums[i] : NEG);
        long long b = (j < n ? nums[j] : NEG);
        long long cur;
        if (a >= b) {  // 取较大者，保证输出序列非递增
            cur = a;
            --i;
        } else {
            cur = b;
            ++j;
        }
        if (first || cur != last) {  // 与上一个输出比较即可去重
            first = false;
            last = cur;
            ++count;
        }
    }

    cout << count << '\n';
    return 0;
}
