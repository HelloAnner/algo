## 题目描述

给定一个正整数 `n`，生成一个包含 `1` 到 `n^2` 所有元素，且元素按顺时针顺序螺旋排列的 `n × n` 正方形矩阵。

## 输入格式

一行一个整数 `n`。

## 输出格式

输出 `n` 行，每行 `n` 个整数，表示生成的矩阵，相邻数字用空格分隔。

## 示例

### 示例 1

输入：
```
3
```

输出：
```
1 2 3
8 9 4
7 6 5
```

解释：从左上角出发，按「向右 → 向下 → 向左 → 向上」的顺序一圈一圈地填 1..9。

### 示例 2

输入：
```
1
```

输出：
```
1
```

解释：`n = 1` 时只有一个格子，直接填 1。

### 示例 3

输入：
```
4
```

输出：
```
1 2 3 4
12 13 14 5
11 16 15 6
10 9 8 7
```

解释：`n = 4` 时外圈填 1..12，内圈填 13..16。

## 数据范围

- `1 <= n <= 20`
- 生成矩阵中的元素互不相同，且恰好是 `1..n^2`
- 要求空间复杂度 O(1) 额外空间（不含返回的矩阵本身）
