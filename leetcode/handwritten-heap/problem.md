## 题目描述

请**手写**一个二叉堆（heap），支持**大根堆**和**小根堆**两种模式，并实现下列操作：

- `push x`：向堆中插入整数 `x`；
- `pop`：删除并输出堆顶元素；
- `peek`：输出堆顶元素（不删除）；
- `size`：输出当前堆中元素个数。

堆用**数组**存储一棵完全二叉树：下标 `i` 的父节点是 `(i-1)/2`，左右孩子是 `2i+1` 和 `2i+2`。
大根堆满足「父节点 ≥ 子节点」，堆顶是最大值；小根堆满足「父节点 ≤ 子节点」，堆顶是最小值。

要求自己实现上浮（shiftUp）与下沉（shiftDown），**不能直接用 `std::priority_queue`**。

## 输入格式

第一行两个整数 `q` 和 `type`：`q` 表示操作个数，`type = 0` 表示小根堆，`type = 1` 表示大根堆。
接下来 `q` 行，每行一个操作，格式为上表四种之一，`push` 后跟一个整数 `x`。

保证 `pop` / `peek` 时堆非空。

## 输出格式

对每个 `pop` / `peek` / `size` 操作输出一行结果：`pop` 输出被删除的堆顶，`peek` 输出当前堆顶，`size` 输出元素个数。
`push` 不产生输出。

## 示例

### 示例 1（小根堆）

输入：
```
8 0
push 5
push 3
push 8
peek
pop
push 1
pop
size
```

输出：
```
3
3
1
2
```

解释：依次插入 5、3、8 后小根堆堆顶是 3，`peek` 输出 3；`pop` 删掉 3 并输出 3；再插入 1 后堆顶是 1，`pop` 输出 1；最后堆里剩 2 个元素。

### 示例 2（大根堆）

输入：
```
7 1
push 5
push 3
push 8
peek
pop
size
pop
```

输出：
```
8
8
2
5
```

解释：同样插入 5、3、8，大根堆堆顶是 8；`pop` 删除 8 后剩 {5, 3}，元素个数 2，再 `pop` 输出 5。

### 示例 3（只有一个元素）

输入：
```
4 0
push 42
peek
pop
size
```

输出：
```
42
42
0
```

解释：堆里只有一个元素时，`pop` 之后不要再做下沉（否则会越界），`size` 变成 0。

## 数据范围

- `1 <= q <= 10^5`
- `type ∈ {0, 1}`
- `-10^9 <= x <= 10^9`
- 任意时刻堆中元素个数不超过 `10^5`
- 时间复杂度要求：`push` / `pop` 为 O(log n)，`peek` / `size` 为 O(1)
