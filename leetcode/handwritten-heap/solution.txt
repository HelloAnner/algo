[思路]

堆是什么：堆是一棵完全二叉树，用数组顺序存储（不用指针），并且满足堆序性质——大根堆里父节点 >= 子节点，小根堆里父节点 <= 子节点，因此根节点就是最值。

因为是完全二叉树，父子关系可以用下标直接算出来（0-based）：

- 下标 i 的父节点：(i - 1) / 2（整除）
- 下标 i 的左孩子：2 * i + 1，右孩子：2 * i + 2

push（上浮 shiftUp）：把新元素放到数组末尾（这样仍然是一棵完全二叉树），然后不断和父节点比较：如果它的优先级比父节点高（小根堆里就是更小）就交换，直到到达根或者不再更优。

pop（下沉 shiftDown）：堆顶就是答案，先取出来；把数组最后一个元素搬到堆顶并删掉末尾（保持完全二叉树形状），然后不断和两个孩子中优先级更高的那个比较：孩子更优就交换，直到叶子或者已经比两个孩子都优。

文档里的 Java 实现用的是「空穴法」：先把末尾元素 x 存起来，然后让空穴一路下移到合适位置再把 x 填进去，比每次都真的 swap 少一半赋值；等价且更省常数，本仓库的 C++ 实现用同样的思路。

大根堆 / 小根堆：两者的代码完全一样，只差比较方向。所以抽出一个 higher(a, b)（a 是否比 b 优先）函数，构造时传一个 bool 就能复用同一份 shiftUp / shiftDown，这也是文档里 Java 版用 Comparator 的用意。

正确性：每次上浮只会把新元素与它的祖先沿路径交换，交换后该路径上父子关系都满足堆序；每次下沉只会让空穴沿「更优先的那个孩子」向下走，交换后父节点不小于（不大于）两个孩子。两条路径都在越界或不满足条件时停止，所以操作结束后堆序性质仍然成立，堆顶自然是最值。

[复杂度]
时间：push O(log n)、pop O(log n)（树高为 log n）、peek / size O(1)   空间：O(n) 存数组

[关键点]
- 下标从 0 开始：孩子是 2i+1 / 2i+2，不是 2i / 2i+1（那是对 1-based 写法）
- pop 时如果堆里只剩 1 个元素，删完不要再下沉，否则访问空数组
- shiftDown 里要「先在左右孩子里挑出更优先的那个」，再和当前节点比，不能只跟左孩子比
- shiftUp 循环条件是 k > 0（根没有父节点），父节点下标是 (k - 1) / 2
- 大根堆和小根堆只差比较方向，抽成 higher(a, b) 后一份代码两用
- 用 long long 存元素更保险（本题 |x| <= 10^9 其实 int 也够）
- 手写堆不能用 std::priority_queue，否则这道题就没意义了——本题要练的正是 shiftUp / shiftDown 的下标推导
- C++ 里直接用 std::vector 的 push_back 即可，均摊 O(1)，不用像文档的 Java 版那样自己写扩容

[C++ 代码]
// 手写堆（大根堆 / 小根堆）
// 题目：讲一讲 heap 是什么，并手写一个堆（《手撕字节跳动面试时出现过的算法题》第 32 题）
//
// 思路：数组存完全二叉树，push 末尾上浮、pop 用末尾元素补堆顶后下沉，比较方向由 higher() 统一。
// 复杂度：push/pop 时间 O(log n)，peek/size O(1)，空间 O(n)
#include <iostream>
#include <string>
#include <utility>
#include <vector>

using namespace std;

class BinaryHeap {
public:
    explicit BinaryHeap(bool minHeap) : minHeap_(minHeap) {}

    void push(long long x) {
        data_.push_back(x);
        shiftUp(static_cast<int>(data_.size()) - 1);
    }

    long long top() const { return data_.front(); }

    long long pop() {
        long long res = data_.front();
        data_.front() = data_.back();
        data_.pop_back();
        if (!data_.empty()) shiftDown(0);
        return res;
    }

    size_t size() const { return data_.size(); }
    bool empty() const { return data_.empty(); }

private:
    // a 是否比 b 更优先（小根堆：更小优先；大根堆：更大优先）
    bool higher(long long a, long long b) const {
        return minHeap_ ? a < b : a > b;
    }

    // 上浮：新元素放在末尾，与父节点比较，更优先就交换
    void shiftUp(int k) {
        while (k > 0) {
            int parent = (k - 1) / 2;
            if (!higher(data_[k], data_[parent])) break;
            swap(data_[k], data_[parent]);
            k = parent;
        }
    }

    // 下沉：在左右孩子里挑更优先的那个，比它差就交换
    void shiftDown(int k) {
        int n = static_cast<int>(data_.size());
        while (true) {
            int best = k;
            int left = 2 * k + 1;
            int right = 2 * k + 2;
            if (left < n && higher(data_[left], data_[best])) best = left;
            if (right < n && higher(data_[right], data_[best])) best = right;
            if (best == k) break;
            swap(data_[k], data_[best]);
            k = best;
        }
    }

    vector<long long> data_;
    bool minHeap_;
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int q, type;
    if (!(cin >> q >> type)) return 0;

    BinaryHeap heap(type == 0);
    string op;
    while (q-- > 0) {
        cin >> op;
        if (op == "push") {
            long long x;
            cin >> x;
            heap.push(x);
        } else if (op == "pop") {
            if (heap.empty()) {
                cout << "empty" << '\n';
            } else {
                cout << heap.pop() << '\n';
            }
        } else if (op == "peek") {
            if (heap.empty()) {
                cout << "empty" << '\n';
            } else {
                cout << heap.top() << '\n';
            }
        } else if (op == "size") {
            cout << heap.size() << '\n';
        }
    }
    return 0;
}
