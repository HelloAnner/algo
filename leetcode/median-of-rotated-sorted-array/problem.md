## 题目描述

一个**严格递增**的整数数组，从某一位被截断，把前一段整体接到了后边（相当于把数组旋转了一次），例如：

```
4 5 6 7 1 2 3
```

给定这样旋转后的数组（也可能没有被旋转，即仍然递增），求它的**中位数**：

- 元素个数 `n` 为奇数时，中位数是排序后正中间的那个数；
- `n` 为偶数时，中位数是排序后中间两个数的平均值。

要求利用「旋转有序」的性质求中位数，不要真的排序。

## 输入格式

第一行一个整数 `n`。
第二行 `n` 个整数 `nums[0..n-1]`，为旋转后的数组，相邻数字用空格分隔。

## 输出格式

输出一行中位数：中位数是整数时直接输出整数（如 `4`），是 `x.5` 时输出一位小数（如 `3.5`）。

## 示例

### 示例 1

输入：
```
7
4 5 6 7 1 2 3
```

输出：
```
4
```

解释：排序后是 `1 2 3 4 5 6 7`，共 7 个数，取正中间的第 4 个，即 4。

### 示例 2

输入：
```
6
6 7 1 2 3 4
```

输出：
```
3.5
```

解释：排序后是 `1 2 3 4 6 7`，中间两个数是 3 和 4，平均值是 3.5。

### 示例 3

输入：
```
5
1 2 3 4 5
```

输出：
```
3
```

解释：数组没有被旋转（旋转量为 0），中位数仍然是 3。

## 数据范围

- `1 <= n <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
- 数组元素互不相同，且是某个严格递增数组旋转一次的结果（允许旋转量为 0）
