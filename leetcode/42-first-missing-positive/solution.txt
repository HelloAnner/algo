[思路]

原地哈希（置换法）。关键观察：长度为 n 的数组，缺失的最小正整数一定在 [1, n + 1] 之间，所以只需要关心值落在 [1, n] 内的元素。

把这 n 个「坑位」看成哈希桶：让值 v 待在下标 v - 1 上。做法是扫一遍数组，只要当前位置的值 v 满足 1 <= v <= n 且 nums[v - 1] != v（它的目标位置还没被正确的值占住），就把 nums[i] 和 nums[v - 1] 交换，直到当前位置的值不需要再动为止。

    值 v 的归宿：v = 1 -> 下标 0，v = 2 -> 下标 1，...，v = n -> 下标 n - 1

    示例 2：nums = [3, 4, -1, 1]，n = 4
      i=0  nums[0]=3，目标下标 2，nums[2]=-1 != 3  ->  交换得 [-1, 4, 3, 1]
           nums[0]=-1 越界，停下
      i=1  nums[1]=4，目标下标 3，nums[3]=1 != 4   ->  交换得 [-1, 1, 3, 4]
           nums[1]=1，目标下标 0，nums[0]=-1 != 1  ->  交换得 [1, -1, 3, 4]
           nums[1]=-1 越界，停下
      i=2  nums[2]=3 == 下标 2 + 1，已经就位
      i=3  nums[3]=4 == 下标 3 + 1，已经就位

      扫描：nums[0]=1 正确；nums[1]=-1 != 2  ->  答案 2

交换结束后再扫一遍：第一个满足 nums[i] != i + 1 的下标 i，说明值 i + 1 没出现过，答案就是 i + 1；如果所有位置都满足，说明 1..n 全部出现，答案是 n + 1。

为什么对：交换的终止条件是「值 v 已经在下标 v - 1 上」，于是结束后凡是 [1, n] 内出现过的值都恰好待在自己的下标上（重复值只能占住一个坑，另一个坑留着不合适的值，正好被第一遍扫描发现）。因此第一个「坑位不对」的位置 i 就是缺失值 i + 1。

为什么是 O(n)：每次交换都会让一个值落到它的最终位置，此后它不会再被换走；值最多归位 n 次，所以内层 while 的总交换次数不超过 n，整体是线性的。

[复杂度]
时间：O(n)（每个元素最多归位一次，两遍扫描）   空间：O(1)（除了输入数组本身不再开额外空间）

[关键点]

- 内层判断必须是 nums[nums[i] - 1] != nums[i]：如果只判断 nums[i] != i + 1，遇到重复元素会来回死循环
- 越界值（<= 0 或 > n）直接跳过，不要参与交换
- 交换时先取一个临时变量，或直接用 std::swap
- 所有位置都正确时答案是 n + 1，别漏掉这个分支
- 元素可能是 2^31 - 1 这种大数，好在只有 [1, n] 的值会被使用，int 足够
- 文档里的 Java 解法即是此思路，C++ 里用 swap 直接原地换

[C++ 代码]
// 缺失的第一个正数（LeetCode 41）
// https://leetcode.cn/problems/first-missing-positive/
//
// 思路：原地哈希——把值 v (1<=v<=n) 换到下标 v-1 上，再从头找第一个 nums[i] != i+1 的位置。
// 复杂度：时间 O(n) 空间 O(1)
#include <algorithm>
#include <iostream>
#include <vector>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    vector<int> nums(n);
    for (auto &x : nums) cin >> x;

    for (int i = 0; i < n; ++i) {
        // 只处理 [1, n] 内的值；目标位置已经是对的就不再动，避免重复元素死循环
        while (nums[i] > 0 && nums[i] <= n && nums[nums[i] - 1] != nums[i]) {
            swap(nums[i], nums[nums[i] - 1]);
        }
    }

    int ans = n + 1;  // 1..n 都出现过时的答案
    for (int i = 0; i < n; ++i) {
        if (nums[i] != i + 1) {
            ans = i + 1;
            break;
        }
    }

    cout << ans << '\n';
    return 0;
}
