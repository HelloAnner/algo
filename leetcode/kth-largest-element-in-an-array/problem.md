## 题目描述

给定整数数组 `nums` 和整数 `k`，请返回数组中第 `k` 个最大的元素。

请注意，你需要找的是数组**排序后**的第 `k` 个最大的元素，而不是第 `k` 个不同的元素。

## 输入格式

第一行两个整数 `n` 和 `k`，分别表示数组长度和要求的第几大。
第二行 `n` 个整数 `nums[0..n-1]`，相邻数字用空格分隔。

## 输出格式

输出一个整数，表示数组中第 `k` 大的元素。

## 示例

### 示例 1

输入：
```
6 2
3 2 1 5 6 4
```

输出：
```
5
```

解释：排序后数组为 `[1, 2, 3, 4, 5, 6]`，第 2 大的元素是 `5`。

### 示例 2

输入：
```
9 4
3 2 3 1 2 4 5 5 6
```

输出：
```
4
```

解释：排序后数组为 `[1, 2, 2, 3, 3, 4, 5, 5, 6]`，第 4 大的元素是 `4`；注意**重复元素各算一个**（不是第 4 个不同的元素）。

## 数据范围

- `1 <= k <= n <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

## 提示

- 请设计时间复杂度优于 `O(n log n)` 的算法（进阶：用堆或快速选择做到 `O(n log k)` / 期望 `O(n)`）。
