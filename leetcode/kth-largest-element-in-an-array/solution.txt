[思路]

小根堆维护「最大的 k 个数」：

- 遍历数组，每读到一个数就压进小根堆；
- 堆的大小超过 k 时，弹出堆顶（堆里最小的那个）；
- 遍历结束后，堆里恰好是全局最大的 k 个数，堆顶是这 k 个数里最小的，也就是全局第 k 大。

为什么对：小根堆的堆顶是堆内最小值，也就是当前「前 k 大」的守门员——任何比它小的元素都不可能是前 k 大，直接淘汰；因此堆里始终保存着已扫描元素中最大的 k 个。扫描完全部元素后，堆顶就是第 k 大。

文档里还给了两种写法：Arrays.sort(nums) 后取 nums[n - k]（O(n log n)，最直白），以及快排的分区思想（快速选择，期望 O(n)）。这里给堆的版本，k 较小时比全排序快。

[复杂度]

时间：O(n log k)   空间：O(k)

每个元素最多入堆一次、出堆一次，堆大小为 k。（排序法为 O(n log n) 时间；快速选择为期望 O(n) 时间、O(1) 空间。）

[关键点]

- 求第 k 大要用小根堆（priority_queue<int, vector<int>, greater<int>>），用默认的大根堆就写反了
- 堆大小超过 k 才弹，注意是 > k 而不是 >= k
- 「第 k 大」= 升序排序后的下标 n - k；不要把「第 k 个不同的元素」当成答案（示例 2 就是反例）
- 不需要真的把数组存下来，边读边入堆即可
- 数据范围下 int 足够

[C++ 代码]
// 数组中的第 K 个最大元素（LeetCode 215）
// https://leetcode.cn/problems/kth-largest-element-in-an-array/
//
// 思路：小根堆维护最大的 k 个数，堆顶即第 k 大。
// 复杂度：时间 O(n log k) 空间 O(k)
#include <functional>
#include <iostream>
#include <queue>
#include <vector>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, k;
    cin >> n >> k;

    // 小根堆：堆顶是这 k 个数里最小的，也就是「前 k 大」的守门员
    priority_queue<int, vector<int>, greater<int>> heap;
    for (int i = 0; i < n; ++i) {
        int x;
        cin >> x;
        heap.push(x);
        if ((int)heap.size() > k) heap.pop();  // 超过 k 个就把最小的淘汰掉
    }

    cout << heap.top() << '\n';
    return 0;
}
